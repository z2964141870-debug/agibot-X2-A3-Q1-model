# X2 MorphMimic 参考窗有界追赶

## Done

沿用 876 个已录就绪周期。861 对相邻、且两端在原记录均被 native 接受的目标用于统计。原人体特征和原关节目标都逐值重现。FGP 间隔取已被接收的人体输入包在桥接端的到达差，按此次窗口最右支持帧回查上一输入包。该间隔没有测量衣服采样或 BLE 时间。

原方案中，窗口只前进 0 或 20 ms 的 549 对里，0 对目标步长超过 10°。超过 10° 的 10 对全部出现在窗口一次前进 40–80 ms 时。按新支持帧之前的输入包间隔分组，10 对分别落在 ≤33.33 ms（1 对）、33.33–60 ms（7 对）和 >60 ms（2 对）。这段数据支持先定位参考窗的突进，输入间隔单独使用时会漏掉部分大目标。100 ms 推进仅 4 对，这一组不足以比较。

新候选默认每周期推进一槽（20 ms）。超过新增参考滞后预算时直接追到预算边界。保留原记录就绪与拒绝序列。模型输入沿用同一组反馈与前序动作历史，人体窗口始终只使用当时已存在的支持帧。两种预算使用同一份录制。

40 ms 预算减少了此段录制的大跳变，但剩余 13.73° 出现在另一个右肘周期（226→227）并且正好触发强制追赶。20 ms 预算的 15.03° 峰值也出现在强制追赶时。两版先保留为离线候选。上述新增滞后是窗口末端采集代理时钟的差，不是链路总延迟。模型没有闭环运行，原接受标签不代表新目标的安全验收，10° 仅用作比较阈值。没有真机命令或部署更改。
