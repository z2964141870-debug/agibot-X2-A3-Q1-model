# X2 键盘行走 —— 终端命令单

> 前提：deploy 已在 CONTROL（策略接管中），rig 兜底，急停有人值守。

---

## 终端 1 —— 键盘控制（操作机器人的手）

```bash
ssh -t -p 22041 agi@100.92.227.62
# 密码 1
~/walk/t2_keyboard.sh
```

看到 `PUB->tcp://127.0.0.1:5563/planner-cmd` 后按键：

| 键 | 动作 |
|---|---|
| `w` | 前进 0.35 m/s（按一下锁定，持续走）|
| `空格` | **停** |
| `a` / `d` | 左转 / 右转 0.65 rad/s |
| `s` | 后退 0.1 m/s |
| `q` | 退出（自动 2 秒缓停归零）|

⚠️ 每按一下必须有回显 `cmd vx=... yaw=...` 才算发出。

## 终端 2 —— 看策略心跳（机器人在不在正常跑）

```bash
ssh -p 22041 agi@100.92.227.62
tmux attach -t x2_deploy
```

- `CONTROL tick` 每秒刷新一行 = 正常
- `pose_ref_age` 从 `-1.000` 变成活值 ≈ 0 = 按键指令已进链路
- `alpha=1.00`、`act_clip=0` = 策略完全接管、无饱和

退出监视：`Ctrl-B` 然后 `D`

## 终端 3 —— 看规划器（指令有没有被吃进去）

```bash
ssh -p 22041 agi@100.92.227.62
tmux attach -t pc2_kplanner
```

- 按键后这里出现 planner_cmd 相关活动 = 指令被接收

退出监视：`Ctrl-B` 然后 `D`

## 操作顺序

1. 开好 3 个终端
2. 终端 1 按 `w` → 走几步
3. 终端 2 / 3 确认链路（tick 在刷、pose_ref_age 活、planner_cmd 有动静）
4. 想停 → 按一次 `空格`
5. 收工 → `空格` → `q` → 叫远程做收尾（deploy 会把 MC 拉回站立姿态再交接）

## 安全顺序

软停 `空格` → 退工具 `q` → 物理急停（现场最终裁量）

## 万一出问题

| 现象 | 动作 |
