# 2026-11-27 具身智能研究简报

本期新增四项与当前瓶颈有关的工作。均为静态核验，没有下载数据、运行代码或改变 Q1 训练主线。

## 1. [Effect-Driven Skill Abstractions](https://arxiv.org/abs/2611.33229)：用“状态会怎样变化”定义技能

这篇工作不只按动作重建误差来量化片段，而是让技能区分“在当前状态执行后会到什么状态”。它用当前状态和动作条件的下一状态预测训练离散技能，规划器选技能，再由低层控制器还原连续动作。与 H004 的潜在动作空间直接相关：需要检查 Q1 世界模型的动作片段是否应该按未来状态效果分簇，而不是只按动作相似度分簇。

作者场景是离线导航/操作 RL，本次未核代码和资产。建议**基线后**，作为 H004 的相关对照，不新增假设。

## 2. [深度传感失效研究](https://arxiv.org/abs/2611.33352)：缺测孔洞可能比噪声更致命

作者用腕部立体相机校准传感器模型，分别模拟深度噪声和缺失孔洞。摘要报告：完整深度带来的成功率提升在噪声放大到 20 倍时仍大部分保留；但约六分之一图像出现深度孔洞时，深度收益消失，validity mask 的处理会显著改变策略是否依赖深度。

它与头环/FGP 的关系是：遮挡、空洞和无效标记应分开记录，不能只报平均深度误差。当前论文是 RGB-D ACT 操作策略，不是 Q1 或头环结果，建议**只作背景**。

## 3. [DexEngine](https://arxiv.org/abs/2611.33579)：把人体示范变成物理可执行的全机器人数据

DexEngine 先把手物体动作放到机械臂可达位置，再做手臂跟踪，最后用物理仿真中的残差强化学习修正轨迹。作者从九个数据集生成约 **65,000 条轨迹、578 小时 episode**，并报告相比浮动手或没有物理修正的训练数据，策略在仿真和真机上更好；这些数字是作者报告。

它对应 Q1 的人体到机器人重定向瓶颈：参考轨迹可达不等于可执行。机器人手臂/灵巧手设定与 Q1 不同，官方 GitHub 入口已核到但未运行，建议**基线后再读**。

## 4. [Beyond the Happy Path](https://arxiv.org/abs/2611.33925)：用失败接触训练世界模型

WorldReforge 对抓取位置、姿态和闭合时机做扰动，生成 **62,000 条**失败/成功接触仿真轨迹，并用接触区域对齐和表面对应训练信号。作者报告对象轨迹误差整体下降 **28.2%**、未见物体下降 **35.0%**；这些是作者报告，尚未复现。

它直接映射 SuperMimic/Q1 的模型误差与评测瓶颈：只用成功跟随片段，世界模型可能不会预测滑移、推开、错抓和交还失败。当前是操作任务、非 Q1 结果，建议**基线后做失败分层评测**。
