## 要训练的模型具体是什么

建议先明确为“全身动作跟踪策略”：机器人接收人体动作转换后的参考，同时读取自己的姿态、关节角和速度等反馈，输出所选控制接口的动作。常见做法是输出关节位置目标或偏移，再由 PD / 执行器执行；输出语义必须依照实际训练配方，不能预设任意策略都输出角度。

```text
衣服 / 头环 -> 人体参考 -> 坐标与时间对齐 -> 机器人参考
机器人反馈 + 机器人参考 -> Actor -> 控制动作 -> PD / 执行器 -> 机器人
机器人的新反馈 -----------------------------------------> 下一时刻
```

人体重建、重定向、动力学平衡策略是不同模块。人体参考与目标角不等于真实电机运动。浮动基座控制、接触和执行器限制决定机器人能否完成参考；固定骨盆的 IK / PD 回放不证明全身策略已经学会平衡。

“自主训练”可以建立在公开代码和预训练权重上：本人能控制任务、数据、配置、训练更新、checkpoint 和评测即可形成自主训练能力。仅播放他人模型不构成训练；使用公开基础模型也不意味着原方法和权重成为独占成果，论文贡献另行验证。

## 路线选择与当前建议

| 条件 | 建议方法 | 必须核验的前提 |
| --- | --- | --- |
| 有同型号、可训练且可复现的策略 | 先复现基线，再针对目标动作微调 | Actor / 配置、观测及动作定义、归一化、机器人资产、训练入口、许可与部署接口匹配 |
| 没有兼容权重，但有可信机器人模型和完整训练任务 | 复用成熟 PPO / 动作跟踪配方，随机初始化训练 | 仿真动力学、执行器、参考数据、奖励 / reset / termination 完整；先做窄任务 |
| 有可运行的强教师或能生成可靠动作标签 | 模仿学习或蒸馏，必要时后续 RL | 教师质量、训练覆盖、学生部署可用输入；教师本身可能仍需先训练 |
| 厂商控制器可用，目标主要是提高输入质量 | 先做参考适配，或评估可学习的参考 / 残差模块 | 明确训练的是哪一层及厂商控制器依赖，不能称已自训全身底层控制器 |

建议优先审计 A3 的同平台预训练路线；Q1 保留为复用成熟跟踪配方、用自有资产训练的备选。尚未决定最终平台；10 月 30 日前选一台为第一训练目标，不同时全量推进两台。

具体理由：

- `AgibotTech/sonic_for_a3` 公开指南明确提供随机初始化与加载 035 PT 权重两种路线，以及 MuJoCo sim2sim、导出和部署说明。训练动作视图是 29 个 A3 驱动关节，头部两关节不在该视图中；配置中的 G1 历史命名不等于硬件目标是 G1。
- 该工程的微调是加载 policy / value 权重后 `resume=false`，优化器、调度器、环境、采样器和步数重新开始。它是已有权重起点上的学习，不能称恢复了原训练全过程。一般微调不必拥有原优化器状态；精确续训需要更多完整状态。
- 公开 PT / ONNX / RKNN 有下载清单，本轮没有下载或验证实际权重。只有 ONNX 推理文件，不等于拥有标准 PPO 可直接继续训练的包。训练配置、网络结构及输入归一化等仍需核验。
- 本地 A3 项目 README 记录普通 A3 T2D5、官方 TA / MC AVATAR 上肢小幅实测；它与新 SONIC 训练工程不是同一条已验证链路。型号名相近仍需查固件、执行器和低层控制权限，不能直接记为可以替换部署。
- A3 当前公开发行缺少 SMPL / teleop encoder，要求上游转换为机器人参考；A3-fast 使用 10 帧、20 ms 间隔的 0–180 ms 参考窗口。实时遥操如何提供这段未来参考是选型必查项：缓冲带来延迟，保持或预测改变输入分布，改为因果学生又增加训练任务。在线评测不得读取录制的真实未来而不计延迟。
- Q1 已有 22DOF 模型、基础关节控制与离线重定向证据；FGP 输入误差、根轨迹、接触、无支撑动力学和训练任务仍有缺口。现有衣服录制被用户限定为 `TEST_ONLY`，本次不改为训练数据。10/9 数据盘点仍在进行，候选文件存在不表示训练库已经通过质量与许可检查。
- G1 checkpoint 不能通过更换关节输出维度自动变成 Q1 策略。机器人本体、动作语义、观测、动力学和执行器都需适配；可复用的是训练方法与工具，权重能否复用必须单独验证。

### 选择前的最小核验

1. 写清准确型号、控制目标与第一动作集合：先站立加低幅上肢跟踪，腿部移动作为下一等级；不把这种小任务等同完整自然遥操。
2. 确认训练源码、配置、资产、许可、可训练权重及匹配归一化；若不能获得兼容权重，转到随机初始化方案。
3. 在选定配置下验证最小训练入口、checkpoint 保存 / 新进程重载及固定片段评测。这里只规定后续验收，本轮未执行。
4. 明确策略运行时所需的机器人反馈和实时参考，尤其未来窗口；若关键传感字段无法提供或低层接口不开放，不把仿真结果承诺成真机可用。
5. 根据实际显存、吞吐、稳定性和评测结果确定训练预算，写清未解决依赖与备选路线。
