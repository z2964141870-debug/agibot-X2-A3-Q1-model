## 补训与迁移

起步渐变只调整完整交还后的参考动作播放速度，身体位置、朝向和关节共用同一小数时间索引，朝向采用同半球归一化四元数插值。开发集在 80% 或 90% 起速、0.6 或 1 秒两种时长及原速间比较，活动候选选为 p90_30。恢复原速后保留积累的参考相位差。控制和物理频率分别为 50 Hz 与 200 Hz。

命令年龄预测器在独立种子的 27,729 行上训练，另用 26,295 行验证。两个 128 单元隐藏层，40 轮共 2,160 次 AdamW 更新，第 32 轮验证最佳。静态和动态命令预测 RMSE 分别为 0.0257 和 0.0413 rad。ONNX 与 PyTorch 最大差 1.8e-07。增益依四种传输条件的静态、五秒动态结果选择，取 0.5。

监督目标按本次命令实际传输时长，在后两拍的原策略目标之间插值。策略输入只取决策时已知的本体量、起身状态、已发命令和实际执行确认。用上次传输时长、最近四次均值、确认的新鲜度与命令差分表征链路。首次接管之前、确认缺失、确认超过 60 ms 或最近确认传输时长为零时输出原目标。训练抖动每五拍重抽 0–30 ms，留出的变延迟条件用不同相位的九拍周期分段波形，两者均含短暂确认丢失。各命令以序号递增方式执行，同一微步只应用最新到达的有效目标。

每个压力条件固定同一组 24 个倒姿与 10 次行走受推。格内为静态通过数 / 五秒续走通过数。起步渐变只运行于行走参考接口，静态列复用完全相同的控制路径。固定预测与延迟重练均使用上一阶段按 20 ms 选定的模型；在线性、固定预测和重练对照中按已知非零延迟启用。

## 复核与复现

归档的三秒基准覆盖 10 条历史轨迹、6,238 拍，位姿、参考、遥测、足载荷及通过判定相同。日常无推直线与八字各 701 拍，四种方案逐帧一致。日常零延迟旁路核对 53,574 拍，渐变前缀核对 23,867 拍。按真实执行确认调用独立推理入口，变延迟接力 7,175 拍、20 ms 静态 7,200 拍与实验入口位姿和遥测一致。

留出集共 112 个完整仿真任务。发出时估算 PD 越限 0 项，到件时限幅前需求越限 14,353 项，物理分段末次采样实际力矩越限 0 项。计数为关节采样，不能据此估计连续时间或真机风险。地面为仿真平地，载荷为骨盆集中质量。
