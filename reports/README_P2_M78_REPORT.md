## 2. 技术结论
1. **靶向过采样机制有效且存在最优区(约 10-15%)**——zj_warmUp 漂移从失控转为受控,是全线唯一对该动作有效的配方手段。
2. 单场过采样存在天敌:占比过高引发分布失衡反噬。
3. 池内 warm-up 数据枯竭(唯一候选)是恢复不完全的根本限制;出路:SMB 747 长会话定向检索 / 多场低占比组合 / 用户裁定量判据容差。
4. 现役最佳保持 **M4b**(布料 50/90,全战果保全)。
