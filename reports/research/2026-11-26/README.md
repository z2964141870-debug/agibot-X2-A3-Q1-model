# 2026-11-26 具身智能研究简报

本期新增三项与当前瓶颈有关的机器人/控制工作。均为静态核验，没有下载数据、运行代码或改变 Q1 训练主线。

## 1. [Sampling at Scale](https://arxiv.org/abs/2611.31561)：把采样搜索和约束计算拆开

DS-TO 让每个 agent 只在自己的控制空间采样，同时通过邻域通信感知约束和其他决策；局部更新可以并行，避免采样维度随邻域规模一起增长。作者在 2D/3D 任务上做到最多 **1024 agents**，报告探索和约束满足优于对照。

它与 SuperMimic/Q1 的关系是采样预算、候选动作筛选和约束开销的参考；多智能体设定与 Q1 不同，也没有 Q1 策略或世界模型证据。建议**基线后背景阅读**，不新增 H005。

## 2. [Exteroceptive Sensor Faults](https://arxiv.org/abs/2611.31667)：把传感器故障变成可复现测试

论文按硬件、环境、标定、软件和组合故障分类，并公开 94 个故障注入例程（相机 41、LiDAR 27、雷达 26）、四级严重度、burst 调度和逐帧标签。它可借鉴到头环 SLAM/FGP 的故障表：遮挡、时间戳跳变、外参偏移、短断流分别触发什么诊断和交还。

当前 setting 是车辆感知，不能直接当头环或 Q1 结果；官方工具入口已核到，但本次未运行。建议**只作背景**。

## 3. [Exact Collision Gradients](https://arxiv.org/abs/2611.31676)：减少碰撞时刻的物理梯度误差

作者指出固定步长模拟在碰撞瞬间会因穿透后才检测和线性 time-of-impact 估计产生梯度误差；方法改用连续碰撞检测并直接对接触条件求导。椭球示例中，作者报告能恢复最优控制和真实参数，而线性估计不能。

它对 Q1 的价值是提醒我们把接触/碰撞模型误差和策略误差分开；论文没有人形、Q1 或 SuperMimic 结果，未核代码。建议**只作物理仿真背景**。

## 处理与边界

H004（Skill-JEPA 潜在动作空间）保持为唯一待验证假设；Sampling at Scale 只补充采样预算背景。Q1 远端自上次检查没有新的工程提交，SONIC kplanner 现场站立基线保持。
