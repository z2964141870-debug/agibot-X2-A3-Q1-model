## 判断与限制

限矩对同动作真实动力学结果有明显影响，侧向髋关节控制权限应列为优先嫌疑；不能由此推导“提高力矩即可行走”。关节误差降低但仍倒地的PD对照显示，关节位置接近与正确的平衡、重心转移和换脚是不同要求。

参考整体降低26.531mm未单独解决早倒，说明此前[足底悬空几何](README_SUPERMIMIC_Q1_FAILURE_REVIEW_20261026.md)不能独自解释全部失败。直接参考PD没有平衡策略或逆动力学前馈，其失败不能证明参考不可能跟踪，更不能成为筛掉训练数据的门槛。

50%组是保存动作的开环反事实，没有重新计算策略闭环动作，只测试122步而非完整365步；接触法向力在控制末状态用`mj_forward`重建，没有记录全部积分子步。限矩与PD参数仅为仿真探针，尚非厂家验证的真机设置。没有用短测改写RF04效果或悄悄改变RF05控制。
