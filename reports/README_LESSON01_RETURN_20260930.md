## 从 reward 到 return

- **reward（奖励）**：每一步的评分。
- **return（累计回报）**：从某一时刻起，把之后的奖励累计起来，通常还会给较远的奖励乘上折扣权重。

先用恰好三步就真正结束的教学任务，设折扣系数 `gamma = 1`，所以第一步开始的回报是 `G = r0 + r1 + r2`。这不是机器人训练参数建议。

以下为两段从相同初始条件出发的**假设经历**，分数不是实测；假设评分同时考虑抬手跟踪与平衡，区别于上一小节仅用误差改善量的玩具评分：

| 经历 | 第一步 reward | 第二步 reward | 第三步 reward | 三步 return |
| --- | --- | --- | --- | --- |
| A：抬得快，随后失稳摔倒 | +5 | +1 | −12 | −6 |
| B：抬得较慢，但保持稳定 | +2 | +2 | +2 | +6 |

只看第一步，A 分数较高；把三步都计入，B 更好。机器人动作训练应考虑后续影响，不能把“当下高分”直接等同于“好动作”。参数更新希望提高预期累计回报，并非保证每次更新、每个回合都提高。

训练时先与环境交互，观察之后发生了什么，再回头利用这段经历学习；不是让实时控制器提前读取真实未来。后续结果受整段动作和环境影响，也不能把一次摔倒全部归因于最初那个动作。如何估计各次决策的贡献，是后续讲价值估计与优势的切入点。

真实 PPO 常用折扣回报和价值估计；采集的一批数据也未必正好在回合结束时截止。本节只使用完整有限回合说明累计评分，不把这里的简单求和等同于完整 PPO 实现。

## 同日反馈：选择 B 的原因与 PPO clip

本题给学员的表格不显示最后一列，请其回答：“先不打折，只看第一步会偏向 A 还是 B？算完整三步后，两者各得多少分，又该偏向哪条经历？”

学员答：“只看第一步肯定要5，效果明显，但是明显不符合PPO要求，需要clip，最好的肯定是2”。

- 只看第一步偏向 A、完整经历偏向 B 的选择正确；学员没有写出三步求和过程，不能记录为已独立算出回报。
- 需要纠正原因：A 的回报为 `5 + 1 - 12 = -6`，B 为 `2 + 2 + 2 = 6`。B 更好来自更高的完整回报，不是因为即时奖励 2 较小，也不是奖励 5 违反 PPO 的数值要求。
- 奖励尺度会影响训练设置，但 PPO 没有“reward = 5 太大，必须裁到 2”的规则。奖励裁剪、执行器动作限幅和 PPO 的概率比裁剪是不同操作。

| 机制 | 在本例中解决什么 |
| --- | --- |
| 回报与优势估计 | 把后续结果纳入评价，为策略更新提供方向；本例完整经历 B 优于 A |
| PPO 的裁剪目标 clip | 在同一批样本上，减弱把策略推得过远的优化激励；不会自动识别或纠正任务评分错误 |

这里谈的是 **PPO-Clip 的策略损失**。它比较同一个观测下、同一个已采样动作在新旧策略中的概率（连续动作则为概率密度）：

```text
ratio = 新策略的动作概率 / 采集该样本的旧策略动作概率
策略目标 = min(ratio × advantage,
               clip(ratio, 1 - epsilon, 1 + epsilon) × advantage)
```

该目标按最大化书写；实现中常对其取负后最小化。`advantage` 暂理解为“这次结果比预期好多少”，下一步再解释估计方法。下面只说明优势为正的一个样本，不概括所有优势符号下的分支。

独立的离散动作教学例子：旧概率 20%，新概率 40%，所以 ratio = 2。设 epsilon = 0.2、advantage = +3，则该样本目标为 `min(2×3, 1.2×3) = 3.6`；当 ratio 超过 1.2 时，再提高该概率不再提高这个样本的裁剪目标。这些数值是数学示例，不是实际训练测量或 X2 配置。

**新概率 40% 不会因此被程序自动改成 24%。** clip 出现在目标函数中，不是新概率、网络参数或机器人目标角的严格硬边界；其他样本、共享参数和损失项也会影响更新。它不保证机器人不摔倒，也不保证每次策略更新有更好表现。

如果评分本身让摔倒经历获得更高的累计回报，单靠减小 clip 的范围不会自动补上正确的任务目标；应检查奖励、终止条件和评估指标。这里也不能从单次假设经历推出某个真实动作永远最好，真实训练优化的是预期回报。
