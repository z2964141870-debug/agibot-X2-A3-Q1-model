# X2 一键穿戴测试与腰部反馈拆分

## 现在怎么测

先按现场官方流程将 X2 置于正常站立。最新 MC 只读回执为 `PASSIVE_DEFAULT`。本次测试只观察策略建议，现有控制器维持机器人状态。

穿好并上电上下衣，在 X2 的 `run` 终端执行：

```bash
~/x2-garment-check
```

收到上下衣提示后按 Enter。用 3 秒摆好 T-pose，静止 3 秒完成标定。随后按终端提示自然站立、抬左臂、放下、抬右臂、放下。动作建议观察约 25 秒。终端实时显示左右肘目标及实测，结束时按五个动作阶段给出中位角和样本量。可用 Ctrl-C 结束。

真人轮保留 `fgp/smpl.jsonl`、`fgp/forward.jsonl`、`policy_trace.jsonl`、`phases.jsonl` 和 `gesture.json`。以 Orin 单调时标和人体窗口支持帧对齐，分别看同侧响应、回落、左踝范围和相邻目标变化。输出全程只读。

## 本轮已验证

- 同一静态 SMPL 站姿和保存反馈下，独立替换模型直接接收的腰俯仰观测，左踝超上限由 187/189 降至 27/189。仅替换由腰俯仰参与推算的骨盆姿态时，左踝转为 186/189 超下限，最大目标变化 41.4°。两通道一起替换仍有 14/189 超下限。这些默认值只用于离线定位。
- 旧保存反馈的腰俯仰约 +20°，策略默认 0°。旧日志捕获的 MC 腰目标为 0°，但这些日志缺少同一时钟下确认 `STAND_DEFAULT` 的记录。当前模式明确为 `PASSIVE_DEFAULT`。需在现场官方站立时重新配对模式及实测腰角，再判定偏差来源。
- 新入口在 Orin 用 599 个已保存 HumanFrame 与真实反馈实测。990 个建议、五段均有输出、1840 条完整记录，丢失 0。窗口支持帧全部能在已记录输入中找到，电机和 SDK 发布均为 0。录制动作没有和这次提示同步，五段数据仅验证记录入口及时间戳。真衣服 SMPL 记录尚需第一次现场测试。
- 首次夹具运行因策略进程误用了衣服目录里的服务接口而无目标。候选随后将策略入口锁定到部署主目录，再次运行通过并安装。旧启动器已保留在板端候选目录。19 项本机运行时回归和阶段时标归类通过。
