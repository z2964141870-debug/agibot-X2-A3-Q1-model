# 2026-11-25 具身智能研究简报

本期新增三项与当前主线相关的公开工作。它们均为静态核验，没有下载数据、运行代码或改变 Q1 训练主线。

## 1. [FoveaWAM](https://arxiv.org/abs/2611.31705)：把动作时效放进世界模型评测

FoveaWAM 用目标中心的 4D 世界动作模型表示当前帧、稀疏 3D 场景流和目标 SE(3) 轨迹，并将推理延迟纳入 OnTimeBench。作者报告 OnTimeBench **82.1%**、RTX 5090 推理约 **15.1 ms**。这类指标比单独看预测误差更接近 Q1 的实际瓶颈：参考是否在有效时间内到达、动作是否仍对应当前目标。

与 SuperMimic/Q1 的关系是评测口径参考，不是直接换模型。当前 H004 仍只验证动作采样空间；FoveaWAM 可作为后续延迟/目标状态对照。项目代码和权重本次未核实，推荐**基线后阅读**。

## 2. [FabricBench](https://arxiv.org/abs/2611.31577)：布料接触与长时域失败基准

FabricBench 提供基于物理的布料操作模拟器，覆盖六类任务和 10,000 个布料资产。作者报告最佳策略平均成功率 **77%**，长时域 T-shirt folding 最高 **36%**，变形状态约 **6–14%**。这说明布料任务的难点常在接触状态和形变分布，而不是只在人体目标重定向。

它与当前 FGP/Q1 的关系是长期衣物方向的评测背景；Q1 当前仍是人形动作跟随，不能把 FabricBench 数字当作 FGP 或 Q1 策略性能。资产未下载，建议**只作背景**。

## 3. [Learning from Human Corrections through Temporal Preferences](https://arxiv.org/abs/2611.31446)：学习“什么时候该接管”

这篇工作把人类纠正看成带时间结构的偏好：纠正前发生了什么、何时介入、介入后哪些状态改善。它与 Q1 的 Planner/human_smpl 切换、交还和退出日志有直接的记录口径关系，但摘要没有给出 Q1 级别的全身或 FGP 结果，也没有核实代码。

建议**只作背景**：先用现有交还门和 kplanner 基线把介入时刻、参考年龄、动作峰值和结果分开统计，不因“学习纠正”标题新增模块。

## 处理与边界

H004（Skill-JEPA 潜在动作空间）保持为唯一待验证假设；FoveaWAM 作为相关评测方法补充，不新建编号。Q1 远端自上次检查没有新的工程提交，SONIC kplanner 现场站立基线保持。
