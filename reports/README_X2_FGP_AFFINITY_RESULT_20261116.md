# X2 MorphMimic 两线程绑核对照

## Done

Orin 新启动后用有线直连恢复。旧 `/tmp` 输出根已不在，未能验证旧任务的退出状态或结果。确认预览锁空且无旧探针后，从已发布的源码在 `/home/run/x2-fgp-affinity-recovered.cQL1vz` 重派一次，此次输出保留在持久目录。退出 0、四轮 CPU 子进程清洁回收、锁已释放、没有测试进程残留，原始结果与 Mac 核对 SHA-256。

保持 FGP 的 GPU CANO、CPU 重建进程和两个在途额度，MorphMimic 固定 2 线程，按不限核、6/7、6/7、不限核跑四轮，每轮使用同一份 240 帧录制 IMU 和固定合成机器人反馈。每轮 211 输出、零跳帧、346 个策略就绪周期。实读策略 ORT 新建线程和状态服务线程，候选核掩码均为 6/7。FGP 数值最大姿态分量差 5.96e-7，根平移最大分量差 9.13e-7 m。
