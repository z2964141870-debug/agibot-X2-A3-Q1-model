# X2 FGP 的 CANO 和标定等待复核

## Done

从保存的四轮 GPU/CPU 分阶段录制读回实际 CUDA 事件和主机时间，每轮 211 帧。逐帧匹配 CANO、360 B D2H 主机调用、显式同步、IMU 标定和线程 CPU 时间。确认慢帧分类与先前的出帧归因一致。没有重新推理。

2 线程两轮里，29 个以 CANO 主机调用为最大耗时增量的长间隔中，26 个最大的 CANO 分项增量在 CUDA Graph 流事件区间。两轮该组 CANO 主机调用增量中位分别为 6.33 和 3.99 ms，调用线程 CPU 只增约 0.10 ms。D2H 主机调用分别增 5.88 和 3.81 ms，D2H 调用线程 CPU 只增 0.012 和 0.025 ms。这些等待与 CUDA 流时间有重叠，不能相加。CUDA Graph 事件区间可以包含流调度和提交等待，现有记录不能区分具体 CUDA kernel、抢占或排队。
