## GigaBrain-WBC：把不同误差分开计分，把带噪输入与监督答案分开

[作者提交](https://github.com/open-gigaai/giga-brain-wbc/commit/73d58601fa7e6b9a3d72d06a40a1cf6088803314)发生于 **11/14 10:16:28 UTC，即北京时间 18:16:28**，本次 11/15 首次核验。它是已有项目的实质源码更新；[论文](https://arxiv.org/abs/2608.18234v5)仍为 11/5 的 v5，不算新论文。

第一处改动是“分别算分再汇总”。以前把许多关节、根部位置和旋转误差放在一起求平均，某项可能仅因维度多或数值大，就主导总分。新版配置先对各个语义组分别求均方误差，再按权重求平均，另记录各组误差。这样更容易看出“总分下降时，移动或关节跟踪有没有被牺牲”。**它改变了优化目标，但没有自动统一米、角度、速度的尺度，也不保证各组梯度均衡。** 源码注释中的误差占比是作者的测量说明，本次未核到对应原始实验，不作为新性能结果转述。

第二处是“输入可以加噪，答案应单独定义”。策略仍使用原来的观测；训练侧新增不加观测噪声的状态副本，供下一状态预测作标签，并保持与策略相同的关节顺序。已读实现用第 t 帧预测对齐第 t+1 帧答案，屏蔽跨回合的配对；干净标签缺失时仍可能回退到原观测。它提醒我们核对标签、时序、顺序和噪声，**不能据此断言 Q1 已存在相同错误。** 静态路径中，干净答案只送入辅助损失，没有作为动作解码器的新输入；训练部署等价性未运行验证。

第三处是可选的“身体下一步怎么移动”。新版默认配置在辅助预测末尾加入机器人根部的位移和旋转变化，位移用当前根部坐标系表达，目标来自机器人实际状态，不是参考动作。G1 示例的辅助头由 64 维变为 73 维，旧权重严格加载需显式处理该开关。作者意图保持现有策略输入和导出接口；本次没有执行加载、导出或兼容性测试。

**与 Q1 的关系及建议：现在读诊断，基线完成后才考虑单变量试验。** 总均方误差是模型对标签的拟合分数，奖励是任务评分，闭环表现是机器人执行后的结果，三者不能互相代替。本次更新适合作为已有分项误差、标签来源和旧能力保持分析的阅读材料。当前仍先取回原人体条件两组已完成训练的审计、七 JSON 和逐点曲线，再按已有计划核多步世界模型；不重训 6000 更新，不据新闻改权重、预算或增加硬门槛。

**证据与资产：**已核固定提交及父提交、完整 627 项树的路径/模式/类型/对象 ID，以及新旧两版九份选读文本共 344429B；七个当前 API blob 与 Git 逐字节一致。项目代码 Apache-2.0，第三方代码、机器人和动作数据另有许可。本提交六处变更未包含新权重或基准工件；本次没有下载权重、数据或执行作者代码。该源码面向 G1/L01，辅助预测并不等于可用于优化动作的可靠物理模型，更不证明真实动作梯度准确。
