## 根因与做法

1. **原校准基线在 2 ms 闭环下侧向锚点稀疏且失衡**：原 Card 04 仅搜索 `strafe_l020` / `strafe_r020` 两个高幅值侧向锚点，且未针对 2 ms 物理步、带 `±0.05 rad` 初始站姿偏差与 `10 ms` 反馈延迟做优化。实测原部署模型在 2 ms 闭环下：`-0.15 ~ -0.08 m/s` 几乎原地踏步不横移（`-0.029 ~ +0.003 m`），`+0.10 / +0.20 m/s` 在停车/后段直接跌倒，24 组扰动初态 + 10 ms 延迟测试仅 **4/24** 通过。
2. **两轮迭代修复**：
   - **第一轮（`v1`）** 在 2 ms 物理下（18 核并行 CEM + 扰动初态与 10 ms 延迟联合评分）搜索 8 个侧向锚点（`vy = ±0.05, ±0.10, ±0.15, ±0.20`），并加入 `multidataset_2000` 的 `sidestep` 与 `multidataset_250` 纯横移编码种子。右侧 `6/6` 和 `vy=+0.05` 通过、扰动+延迟升至 `22/24`，但发现三个待修缺陷：① CEM 仅测 4 s 起步未测“站立→横移→平滑刹停”，导致 `+0.10 / +0.12 / +0.15` 在 5.0 s 后停车阶段跌倒；② Stage 2 缺失 `±vy → 0` 减速斜坡分布；③ 锚点锁定权重过弱（`0.10`），使 `walk_f035` 与侧向锚点出现 `0.10–0.20` L2 漂移。
   - **第二轮（`v2`）** 保留 `v1` 已稳的 5 个侧向锚点与全部 11 个非横移锚点，在完整 **`stand_0 → cmd → smooth stop → stand_0`** 2 ms 闭环下精修 `strafe_l010 / l015 / l020`；Stage 2 加入 `±vy → 0` 减速斜坡并将精确锚点锁权重提升至 `0.28`（`4500` 步，`vy` RBF 尺度 `0.035`），全部检查锚点导出 L2 误差收敛至 **`0.0188–0.0453`**（余弦相似度 **`0.99984–0.99997`**）。
