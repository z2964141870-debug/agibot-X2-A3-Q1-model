# X2 MorphMimic 独立录制验证

## Done

用两份独立于 11 月 15 日只读异常会话的人体录制 `orin_real_active` 和 `orin_real_worn` 验证原取窗、20 ms 和 40 ms 滞后上限。每份录制 599 个人体包，保留包内捕获时间和原回放到达时间。两份各做原样回放及删除中点连续八包（299–306）的合成断流。Mac 用同一份 CPU ONNX 策略和固定合成机器人反馈，三个方案分别递推各自的上一动作历史。三个方案的逐周期就绪及拒绝原因完全一致。这里没有真实反馈闭环，也没有重新运行 FGP 或物理。

| 录制与情形 | 就绪周期 | 最大连续目标跳变（原 / 20 / 40 ms） | 连续跳变超过 10°（原 / 20 / 40 ms） |
| --- | ---: | ---: | ---: |
| active，原样 | 1722 | 14.41° / 11.49° / 11.49° | 6 / 3 / 2 |
| active，删八包 | 1687 | 14.41° / 11.49° / 11.49° | 6 / 3 / 2 |
| worn，原样 | 989 | 30.12° / 23.17° / 23.17° | 7 / 6 / 6 |
| worn，删八包 | 970 | 30.12° / 23.17° / 23.17° | 7 / 6 / 6 |

两种预算的额外参考窗滞后上限均达到设定值。合成断流分别产生连续 35 和 19 个无目标周期，恢复后的第一条目标与断前末条相差约 0.82° 和 2.94°。active 录制本身另有一次连续 11 个无目标周期，参考窗跨过 320 ms，恢复第一条左肘目标相对断前末条跳约 28.33°，两个有界方案都未改善。断流恢复另列，与正常连续周期的峰值分别统计。

worn 的残余峰值为右踝俯仰，窗口只前进 20 ms 也出现约 23.17° 跳变。worn 上 40 ms 额外滞后的方案没有进一步降低峰值，且相对原方案的目标偏差最大达 39.18°。目标偏差是两套离线策略输出差，不是人体跟踪误差。两种方案先保留为候选，现场维持暂停。
