# Q1 Planner 真机反馈与模型训练摘要

**日期**：2026-11-21
**策略**：Pure V2b `planner_cmd`，`q1_tok_planner_cmd.onnx` 采用 h003 calibrated 版本
**控制模式**：低层开发模式，外部 3090 运行 ONNX，ROS 2 发送 `/aima/hal/joint/command`

## 结论

- 低层控制链路已经打通。键盘命令能够进入策略，策略能够持续发布完整 22 关节命令，HAL 有订阅者，前进、后退和原地转向在真机上表现稳定。
- 左移和右移经过多次速度尝试仍然不稳定，表现为侧向步态难以持续、横向位移不足或姿态调整明显。`a=+vy`、`d=-vy` 的符号映射已经与训练和离线标定一致。
- 当前问题集中在侧向步态的策略输出与真机动力学匹配，控制输入链路本身没有发现丢失或映射错误。
- 真机横移试验没有逐次记录命令速度标签。现有日志能完整支持一次运行的反馈统计，用户对多组速度的结论属于现场重复观察。

## 已验证的真机成果

### 低层站立和控制链路

此前的低层自承重验证中，吊绳放松后机器人仍由策略承重。连续 5 秒只读监测得到以下结果。

| 指标 | 结果 |
|---|---:|
| IMU 倾角中位数 | `1.675°` |
| IMU 倾角 P5–P95 | `1.671–1.686°` |
| 最大关节速度 | `0.00733 rad/s` |
| 倾角 RMS 波动 | `0.00036°` |
| 控制进程持续时间 | 约 `2 分 45 秒` |

这证明 Pure V2b 站立保持和低层持续发布路径可以在 Q1 上承重运行。

### 真机运动表现

| 方向 | 真机观察 |
|---|---|
| `w` 前进 | 稳定，可持续形成步态 |
| `s` 后退 | 稳定性明显好于横移 |
| `q/e` 原地转向 | 稳定 |
| `a/d` 左右横移 | 多个速度下仍不稳定，难以持续横向行走 |

真机没有绝对位置或足底力真值，因此本轮不能从 HAL 日志计算实际米制位移、侧向速度或滑移距离。现有监控主要提供 IMU、关节状态、反馈年龄和命令发布状态。

## 横移相关的离线证据

### Planner 标定锚点

文件 [planner_cem_anchors.json](../../SuperMimicHP/runs/h003_v2b_planner_cal/planner_cem_anchors.json) 中包含侧向锚点。

| 目标命令 | CEM 评分 |
|---|---:|
| `vx=0.18, vy=0` | `-0.948` |
| `vx=-0.20, vy=0` | `-0.936` |
| `vx=0, vy=+0.20` | `-3.010` |
| `vx=0, vy=-0.20` | `-2.925` |
| `vx=0, vy=0, wz=+0.50` | `-0.460` |
| `vx=0, vy=0, wz=-0.50` | `-0.320` |

侧向锚点评分明显低于前后和转向锚点。这个结果来自相同的离线 CEM 目标，说明横移在模型训练和策略 latent 空间中本来就更脆弱。

### 当前 calibrated tokenizer 的侧向输入扫描

使用部署中的 `q1_tok_planner_cmd.onnx` 和离线 MuJoCo 评估函数，对恒定横移输入得到以下校准分数。分数越接近 0 表示该离线目标越好，不能直接当作真机位移。

| `vy` | 离线评估分数 |
|---:|---:|
| `+0.05` | `-1.276` |
| `+0.10` | `-3.629` |
| `+0.15` | `-1.948` |
| `+0.20` | `-7.267` |
| `-0.05` | `-1.125` |
| `-0.10` | `-2.879` |
| `-0.15` | `-1.977` |
| `-0.20` | `-5.126` |

侧向响应随速度不是单调改善。`|vy|=0.20` 已进入明显较差的区域，`|vy|=0.05` 的离线分数最好，但低速并不代表真机一定能产生足够横向位移。

## 对模型训练端的直接信息

1. 保留当前 `planner_cmd` 的前后和转向训练结果。真机已经证明这两类命令能够工作。
2. 增加独立的左右横移训练和验收集，至少分别覆盖 `vy=±0.05、±0.10、±0.15、±0.20`，并记录真实横向位移、步宽、横滚、足底滑移和跌倒门控。
3. 训练数据应保持 planner 的连续 10 帧历史、平滑速度过渡、`p_ref_xy` 和 `R_ref`。当前真机桥接已经补上这套参考流。
4. 对左右横移分别做镜像一致性检查。当前离线分数 `+vy` 和 `-vy` 都比前后走差，且两侧分数并不完全对称。
5. 训练时加入带初始姿态偏差的侧向恢复样本。真机低层接管后的实际站姿与策略 `default_q` 存在明显偏差，侧向动作对这种偏差更敏感。
6. 训练端需要输出侧向动作的足底接触相位、左右髋滚转、踝滚转和横滚反馈，便于区分“没有迈步”和“迈步后滑移”。
