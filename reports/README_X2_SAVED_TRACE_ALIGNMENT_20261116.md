# X2 遥操异常逐帧对照

## Done

### MorphMimic

从 SoC1 原件按人体序号、采集时间和机器人反馈序号对齐了 988 帧 FGP 输入、876 个就绪的策略周期。每个就绪周期的全部 10 个参考槽都能查回原始人体支持帧。服务记录中的 ONNX 动作与回复一致，回复又与 native 侧收到的值一致。原 Tolerant 实控事故单独复核，左髋相邻目标跳变 95.63°，这一帧 RPC 8.32 ms。事故没有原始人体窗口、ONNX 特征或 500 Hz writer 实发目标；因此只能缩小到策略目标已异常，无法用事后录制判定同一个首因。

另一次完整只读录制，最大的相邻且被接受的目标跳变出现在反馈序号 268→269 的右肘，19.97°。两轮 RPC 为 16.64 和 15.60 ms；关节位置和速度回读相同，IMU 朝向仅差 0.0023°。新近人体源帧 6297→6298 的 24 关节世界朝向最大相对转角为 9.96°，参考时间窗整体推进了 60 ms。同槽位窗口朝向最大变化 29.85°，其中也包含窗口向前滑动时读到的其他支持帧。

用同一个权重和原运行时的 action_human 子图做 8 个离线交叉输入。两个原始端点的 ONNX 动作逐值重现，以下数值均为相对第一帧的右肘目标变化：

| 换成第二帧的输入 | 右肘目标变化 |
| --- | ---: |
| 只换人体参考特征及对应 mask | +19.4946° |
| 只换关节/IMU 的本体历史 | +0.0024° |
| 只换前序策略动作历史 | +0.5701° |
| 全换 | +19.9713° |

这对相邻帧上，变化主要从**合成的人体参考特征进入策略**，并传到后端目标。人体特征已在录制中完成坐标及朝向处理，交叉张量可隔离其作用，尚不能区分真人动作、FGP 重建和取窗时序各自的贡献。该结论只覆盖右肘这对只读样本。首轮重放误用未裁剪的双接口 ONNX，因缺 motion 输入在前向前退出。改用部署原有的 human 子图后，8 个组合全部通过。

### SONIC

复核了独立的历史离线对照，使用同一 v16 checkpoint 并固定各对照内的机器人反馈，替换站立参考或前序动作历史。旧影子前缀中，换 kplanner 参考后腰横滚原始目标 P95 从 137.14° 到 157.82°。保持备用站立参考，仅离线置零前序动作历史时为 0.45°；使用回填自身预测动作历史时为 137.25°。这些是保存反馈上的模型敏感性，参考窗口为离线重建。十月录制的独立前缀也未证明换 kplanner 就会消除大目标。历史对照没有以反馈闭环验证清空动作历史的效果，不能据此改部署。

先转 kplanner 站稳，再进 tracking 仍是要复验的切换路径。此前 130° 级影子输出峰值来自渐入重置，切前大腰部目标已存在，因此复验需要同时监控**切换前的参考与动作**以及切换帧的渐入、原始动作和最终目标。
