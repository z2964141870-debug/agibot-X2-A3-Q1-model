记录日期：2026-10-23，北京时间。阶段：SM-A3-DATA01。状态：数据盘点完成；发现 M02 时间基准错误，R05 已于 11:01 正常保存并停止，进程/收据/最终文件大小与 SHA 独立核验通过。本文优先于此前把 A3 CSV 标为源 30Hz 的说明。

## 目标与范围

用户要求彻底明确可用于训练的数据。本轮在 huanyu `/opt/data/private/yuanqi_ops` 只读核对目录、ZIP 中央目录、来源文档、小型 JSON 和源码身份；没有新推理、IK、物理采样或 optimizer 更新。既有 R05 在盘点开始时仍运行，本节不把同时发生的旧作业计算记成本次盘点计算。

## 两种训练原料

1. **动作参考**：规定机器人应完成的身体运动。已有 A3 动作最接近当前接口；人体 SMPL/SMPL-X/BVH 等表示和其他机器人动作需要先转换为 A3 参考。至少明确时间、根位置/朝向、关节/身体运动；接触及速度可以按明确方法推导，不能用填零掩盖缺失。参考不要求自带专家控制力矩或成功控制轨迹。
2. **动力学转移**：当前策略在 A3 物理仿真中产生的状态、实际动作、下一状态和终止标签，用来拟合世界模型。人体动作文件、G1 状态和原始 IMU 都不是 A3 动力学转移。既有 replay 可作为身份明确的历史资料，是否复用需由独立实验决定，不能当作自动训练许可。

SuperMimic 的核心循环是当前策略采集物理转移、拟合可微世界模型、在模型中更新策略，再回物理仿真。动作库规定目标，物理引擎提供后果；两类原料不能混计。

## 关键纠正：当前参考被放慢四倍

固定 vendor 的 `docs/a3_training2sim2deploy.md:236` 明确 selected20 CSV 为 **120Hz**，示例 `--fps_source 120`。文档 SHA `7240718c9ee7bf626d9b39e8ed64142c3ed4b06b24e6fe1f931d43a453a70635`。

本工程 `prepare_motion.py:29` 却以 `np.arange(n) / 30.` 建立源时间，71 行登记 source_hz=30；源码 SHA `d2bda2d483adc1064b0f31d687892ff5bdb91c48371210af0ac97ec64a5d4134`。输出 50Hz 本身没有消除错误；相对文档的原始时间轴，M02 动作被拉长 4 倍，速度约为原速 1/4。全部 20 源 CSV 身份与 M02 完全匹配，不能解释成后来换了不同输入。

因此 R02/R03/R04 和当前 R05 的完整回报、完成比例、实际运行秒数仍是该慢放条件下的真实仿真记录；**不证明原速动作跟踪能力，也不能用于原速 SONIC/035 或论文效率比较**。旧记录保留并以本条纠正解释，不能只把 JSON 的 source_hz 改成 120：必须重新采样，并重算 qvel、身体速度和相关参考量。

本轮没有修改冻结的后端、训练代码、M02 NPZ、已完成模型或旧终态。修正后的原速数据需要独立新目录、质量检查、初态基线和新实验，不能把旧学习率或训练回报直接延续解释为原速进步。保留旧模型便于研究时间变换，是否迁移初始化需重新验证。

## 数据接入顺序与用途划分

建议先纠正 selected20 并验证少量基本动作的原速闭环，再从当前已有 PHUMA 或合法可访问的人体动作源建立批量 A3 重定向与质检流程。FGP/CLOTHO 数据用于最终传感衣域适配和感知误差研究。90 份历史拟合文件是候选资产，不默认作为高质量训练集。

已知七段人体标签内部检查曾通过，但对应早期 A3 重定向 0/7 过门；近期肩点诊断仍存在未修几何问题。证据支持先检查转换链，不能直接说人体原始数据无用；见[标签语料 E14](README_A3_SMPL_CORPUS_20261012.md)、[肩点 T13](README_TELEOP_A3_SHOULDER_PROBE_20261022.md)。旧失败阶段不重跑。

训练、开发、最终测试按**原始录制/原始 motion 身份**划分；先划分再切窗、重定向或数据增强。同一录制的 G1/H1/A3 版本、不同速度、镜像和重叠窗口不能分散到训练与最终测试。已有四段开发参考、v7 及反复诊断的衣服会话不当成未触及测试。

动作能作为训练参考与能作为论文精度真值是两回事。伪参考可以用于明确标注的训练或噪声适配，但验证衣服感知精度仍需独立可信人体真值；验证移动跟随还需可靠世界根轨迹。
