# 实验记录模板

复制为单独记录后填写。“未知”也是有效记录，不要用猜测补齐。

## 问题与假设

- 实验编号 / 日期：
- 要回答的一句话问题：
- 假设与可能否定它的结果：
- 本次唯一主要变量：
- 对照组 / 方法组：

## 版本与环境

- 机器人准确型号 / 仿真模型及其 SHA-256：
- 训练代码版本与未提交改动：
- 仿真器 / Python / PyTorch / CUDA / GPU：
- 配置路径、随机种子、并行环境数、训练步数：
- 模型 checkpoint / 导出模型 / 归一化参数的路径与哈希：
- 动作数据来源、片段清单、训练/验证/测试划分：
- 观测、action、关节顺序、坐标系及单位：
- 仿真步长、policy 周期、下游控制周期：
- 输入历史和未来窗口；实时可获得性；实际延迟如何测量：

## 执行前确定的判据

- 动作任务、时长、重复次数与完成定义：
- 失败与终止定义：
- 主要指标与统计方式：
- 次要指标与需要控制的混杂因素：
- 通过阈值的依据：

## 执行与结果

- 可复制命令：
- 运行日志、配置快照、曲线、视频的位置：
- 完成次数 / 总次数，失败类型与发生时刻：
- 跟踪误差、滑移、机身姿态、延迟及波动：
- 训练奖励与独立评测是否一致：
- 异常、重试、排除数据及原因：

## 结论与下一步

- 证据支持的最窄结论：
- 尚不能推出的结论：
- 主要假设得到支持 / 被否定 / 证据不足：
- 下一次只改什么，为什么：

科研比较应保持评测数据与参数选择数据分离。发生失败的日志同样保留。涉及真机时，另引用该平台既有现场流程和当前版本验收记录。
