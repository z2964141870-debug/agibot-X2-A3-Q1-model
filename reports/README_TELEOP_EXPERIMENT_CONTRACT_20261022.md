# 传感衣遥操：首轮对照合同（待真实数据准入）

日期：2026-10-22。阶段T01；状态：合同及标准库校验完成，尚未运行新推理/仿真/训练。目标是提升人穿传感衣的遥操，不是机器人操作布料。

## 研究问题与先后顺序
不预设FGP、重定向或策略哪一层有错。先区分三种误差：人体重建误差；同一人体意图映射到机器人参考的误差；机器人闭环相对共同目标的执行误差。仅降低相对有噪参考的误差，可能只是更忠实模仿错误，不能称遥操改善。

### T01 一条数据配对准入
先固定同一capture/session的原始IMU、FGP预测、可信标签来源、坐标单位、源帧索引和共同时间区间。历史推理暖机后输出从源帧59开始，不能拿预测数组0对标签0。11槽原始IMU去槽5与10槽denoised张量不可混用。30Hz只为代码合同，设备真实时序另核。

train_released包仅分布内诊断，不证明FGP泛化。SMB与demo100是否被各FGP checkpoint见过未知。没有可审计标签时只做输入自洽与可行性诊断，不编造GT或世界根轨迹。禁止任取5GT动作加5FGP动作做FGP因果比较。

### T02 首轮冻结035对照（配对通过后）
开发集3–5个完整会话，事先列出，不只选失败场次。各方法用同一原始数据和目标、重定向参数、源帧范围、reset/历史填充、控制时序和种子；参考转换版本分别登记SHA。第一轮单候选，不用完整测试结局选最优。保留GT标签输入与FGP输入两条参考，分别测共同目标跟踪与相对自身参考误差；标签输入不是保证更好的物理上界。

先只035，确认指标与接口后才增加M17策略对照。M17在旧朝向/跌倒门上的成绩不能充当新指标已优于035。sim2sim是第一闭环，但同时记录关节RMSE、根相对腕/脚误差、根朝向/位移（有可信来源时）、动作变化及全程跌倒，不能等投稿前才补质量指标。

## 终点与统计
- 主终点：完整任务（含接入/暖机）的成功；任何早倒是失败，不删出分母。缺失、超时、步数不全记INVALID，并报告覆盖率，不记成功。
- 同时报跟踪质量与时延。不仅测不倒，也防止站着不动拿高分。
- 固定同一目标区间；额外准备段时间另报。条件存活率可作副指标，但分母必须是实际完成接入者，不能替代完整成功率。
- 同会话多锚点、重复seed不是独立会话；按受试者优先/会话次之聚类配对不确定性。小样本仅探索，不为追p值扩样。
- 在开发集观察到有用方向后冻结方法和参数，锁定未参与挑选的新会话测试。效用门建议为配对跟踪误差至少改善5%、不新增完整任务跌倒、时延与安全代价在预先给定部署预算内；此门是后续候选筛查，不是现成效果或临床式保证。
