## 1. OCLO：人只指定双手目标，机器人自行选择身体姿态

**10/8 更正：**作者项目页现已明确输入为“双手目标＋行走速度”，真机另用 G1 摇杆控制行走；省去的是显式骨盆/躯干姿态指令。下文“只指定双手目标”是 10/7 根据当时 v1 与项目页作出的不完整概括，不能理解为双手位姿自动决定所有行走意图。arXiv v1 本次未变，项目页修订时间未提供；两日缓存差异见[10/8 简报](../2026-10-08/README.md)。历史原文保留以便核查。

拿低处的箱子时，手到哪里容易指定，但该蹲多低、腰怎么转，不能只靠手臂解决。[OCLO 原文](https://arxiv.org/html/2610.05678v1)把工作拆开：手臂用逆运动学跟踪目标；腿和腰用 PPO 学习支撑、移动和受力后的协调；简单的可达性规则根据手目标生成骨盆高度和躯干姿态，再可选地用仿真试算细调。

这与我们的头环手/腕控制直接相关：以后可比较“追踪人的全身姿态”和“准确追踪双手、由机器人选择支撑姿态”，尤其是人和机器人身材不同、手要伸向低处时。但后者会改变全身模仿的任务定义，不能直接视为替代衣服/SMPL 链路。

论文所说“不用数据集”具体指**不用人体动作示范数据**。仍要由 PPO 在仿真中采集经历，按站走、手部触达与受力、蹲伏姿态三阶段训练。这正好呼应我们学过的强化学习数据来源。

**证据与边界：**已读原摘要、方法、相关实验与局限，并核验[项目页](https://oclo-humanoid.github.io/)；代码仍标为 Coming Soon，权重/训练资产未核验。作者报告 G1 七项定性任务和 SONIC 上的姿态模块实验；真机交互力由电机力矩估算，非腕部力传感器直接测量。七项任务用轻量姿态规则，仿真试算版本的真机测试使用固定手目标、外置 CPU；不能把它全部等同于实时动态遥操验证。

**建议：基线完成后再试。**先借鉴分阶段训练和姿态接口；人形跟踪基线完成后，再用固定手目标比较固定站姿、简单姿态规则与更复杂规划。今天不更换训练框架。

## 2. VICON：遮挡时，先确认手是否真的抓着物体

视觉看不清物体时，直接跟随手可能出错：手已经松开，物体并不会继续跟着走。[VICON 原文](https://arxiv.org/html/2610.05180v1)用视觉惯性手套、RGB-D 相机和压力传感器一起记录：看得清就多信视觉；确认抓住时才让手的运动帮助估计物体轨迹。它估计的是**手与物体的交互记录**，不是单凭头环恢复一切。

作者在五个刚体、40 段有动捕参考的录制中，报告物体跟踪失败帧比例从 FoundationPose 的 50.9% 降到 2.5%。这是作者报告的系统比较；VICON 多用了手套和接触输入，不能解释为同样输入下只换算法的提升。

**证据与边界：**已读方法、评测、消融与局限。关键修复是**录完后的离线优化**，会利用遮挡前后信息；额外需要带 IMU/标记的手套和八个压力传感器，并有固定抓握假设，尚不能证明实时头环遮挡恢复效果。[官方仓库](https://github.com/VICON-dataset/dataset)当前根目录只有 README，内容为数据将在发表后发布；没有核验到数据、训练代码、权重或明确许可证。仓库核验提交为 `28bb3150e0fc02aa713eea3632ac9a5a7e944fe1`。此论文名称不指商业 Vicon 动捕产品。

**建议：基线完成后再试。**可借鉴接触状态、可见度和可靠性标注；先确认已有设备实际能输出什么，不据此购买或接入新硬件。离线数据清理与实时遥操需要分别评测。

## 3. Continual Humanoid Motion Learning：学新动作时，少改旧本领

学会走路后再训练跳跃，直接微调同一个网络可能把走路能力破坏。[这篇论文](https://arxiv.org/html/2610.04231v1)保留已经学好的网络分支，给新动作增加较小的 LoRA 可训练模块；先比较动作相似程度，再决定从哪个旧技能继承、给新模块多大容量，最后蒸馏成可部署控制器。

对我们有用的是“先学好一个，再有控制地添加技能”的实验思路。**LoRA 从语言模型迁到人形动作学习已经有明确先例**；仅把 LoRA 用到智元，不能直接称为新算法创新。

**证据与边界：**已读方法、训练协议、效率消融与部署相关正文，未复现。作者的效率数字针对可训练参数和指定训练预算，不等于总模型体积同比缩小；旧分支与连接仍会增长。实验给定任务标识，并使用人体动作参考，不证明机器人能自行判断未知新技能。作者给出[匿名代码入口](https://anonymous.4open.science/r/continual-humanoid-learning-35D3)，本次 HTTP 401、`not_connected`，实现、许可证和权重可用性无法确认。

**建议：基线完成后再试。**先完成一个可靠的人形跟踪策略；以后加入第二类动作时，保留旧动作评测，与直接微调、从头训练及固定容量适配比较，再判断是否需要持续学习方法。
