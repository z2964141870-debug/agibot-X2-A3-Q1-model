# X2 衣服一键只读测试

在 SoC1 的 `run` 账号执行以下命令。上衣和裤子先上电并穿好。

```bash
~/x2-garment-check
```

收到上下衣提示后按 Enter。先有 3 秒摆 T-pose，再静止采集 3 秒。看到「人体帧已到策略」后，自然站立，慢抬左臂、放下，再慢抬右臂。终端显示两侧肘关节建议和实测、目标最大步长、目标和实测最大差、超区间次数以及拒绝原因。策略观察 25 秒后退出，Ctrl-C 可提前结束。日志保存在命令打印的目录。

## Done

入口自动启动板端已有无网页 S1 GPU、MorphMimic 策略和原生 observe。继承现有 120 ms 新鲜度和 100 ms 插值间隔，原生策略 RPC 预算为该 30 ms 测试配置。已核对板端衣服入口的实际参数。独立接收候选未部署到衣服流程。

- 原生空输入冒烟收到 297 次带真实反馈的请求，人体未接入，电机发布 0。
- 另在同一启动链路按原时标送入 220 个录制人体帧。有 278/284 个策略请求生成建议，但其中 248 条左踝横滚目标超出当前配置区间，建议与当时实测最大差 46.9°（右肘）。录制人体与当前机器人姿态属于不同时间，不能从该差值断言穿戴动作表现。
- 原生 `observe` 回执的电机命令和 SDK 发布均为 0，MC 无改变。现场真人 BLE、标定和电机跟随需分别验证。本命令观测目标，电机仍由现有控制器管理。
