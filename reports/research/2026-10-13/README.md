## 1. PriMoRetarget：先保住脚与接触，再追求姿态相似

**问题：** 人体动作转成机器人动作时，姿态、脚的位置、接触和平滑等目标会相互冲突。把它们加权求和，即便把脚的权重调大，也可能为了改善其他目标而牺牲脚的位置。

**方法：** 给目标明确排序，把低优先级的更新方向投影到不破坏高优先级误差的方向。论文实验顺序为脚位置、交互接触、其余姿态/交互目标；这是在每次更新附近的一阶约束。地面穿透、关节限位和平滑在其实现中属于直接加入梯度的自由目标，不能据此声称严格不穿地。

**与我们有关：** 当前 A3 参考转换仍在位置精度与脚地面几何之间取舍。它给我们一个可比较的目标组织方式。建议**现在读方法并保留为离线对照候选**，先完成既定几何核验，参考合格后再评测策略。学习时可用“脚不能为了胳膊更像而随意移动”理解优先级。

**证据/资产/局限：** 已核验方法、自由目标、实验协议、局限和作者页。作者页写 Code coming soon，训练代码、权重及动作数据当前未核验。目标顺序仍人工指定；源动作的穿透与抖动可能保留；单人动作中与加权方案的差别有限，交互任务更明显。G1 等结果不证明智元支持，更不是实时遥操部署证明。

原文：[摘要与日期](https://arxiv.org/abs/2610.12642) · [相关正文](https://arxiv.org/html/2610.12642v1) · [作者页](https://nickioan.github.io/primoretarget-page/)。

## 2. Reflex：先学控制，再接感知；冻结发生在哪一步要说清

**问题与方法：** 机器人用第一视角接住抛来的箱子，同时面对身体平衡、视觉延迟和遮挡。作者先用 PPO 学状态控制；再把有延迟/缺测的物体观测变成中间表示，并联合优化编码器和控制解码器；最后冻结这两部分，只训练 RGB-D 历史与相机运动到中间表示的视觉模型。**不是整个流程都冻结底层。**

**与我们有关：** 提示我们把“衣服/头环提供可用参考”和“身体策略稳定执行”分开验收，定位到哪一层失败再改哪一层。它不提供把任意 SMPL 编码器直接接到 A3 官方表示的办法，A3 输入含义仍须自己的成对数据与接口验证。建议**基线完成后再试适配；现在借鉴分阶段验收**。

**证据/资产/局限：** 已核验训练、对照、硬件与局限段落；未在已查论文入口确认公开训练代码或权重。作者报告 G1 真机 2.5/5 米投掷成功率为 65%/40%，每条件仅 20 次；远距离视觉是明显短板。其公平探测器对照显示，学习式时间模型未全面优于调好的卡尔曼滤波；硬件延迟数据来自探测器管线，不能当作所有视觉方案的端到端时延。均未由我们复现。

原文：[摘要与日期](https://arxiv.org/abs/2610.12772) · [相关正文](https://arxiv.org/html/2610.12772v1)。

## 3. PanTact：衣服与头环之外，接触信息也可以成为任务输入

**问题与方法：** 只记录人体姿态，不一定知道手臂或膝盖正在撑住、推压或分担负载。PanTact 在第一视角/双手采集系统上增加模块化接触贴片，记录接触位置、时刻与强度；策略预测接触目标，由全身控制器用机器人合适的身体表面实现目标。

**与我们有关：** 给自然遥操的未来扩展一个方向：让操作者传递“哪里需要支撑/接触”，而不只是“关节摆成什么样”。当前先保留数据字段和标定思路，建议**只作背景，身体跟踪基线后再评估**，本次不采购或安装硬件。

**证据/资产/局限：** 已核验传感器、控制、同步/部署附录和作者页；作者页 Code 按钮的 href 为空，不能记成代码已开源。G1 演示不是智元部署证据；控制用二值接触与位置，不等于精确复现人体接触力。其采集流共享同一单调时钟，再离线对齐；这一条件不能直接解决我们的跨设备同步。机器人执行坐标另依赖头部 LiDAR/惯性定位，不等于现有头环能提供同样输入。

原文：[摘要与日期](https://arxiv.org/abs/2610.12558) · [相关正文](https://arxiv.org/html/2610.12558v1) · [作者页](https://pantact.github.io/)。
