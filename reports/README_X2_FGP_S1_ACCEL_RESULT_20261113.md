# FGP S1 加速结果

2026-11-13。已确认用户提供的`cano_ep120.pth.1`是S1，和现有ONNX导出来源SHA完全一致；144模型张量约90.7MiB参数，272MiB原文件另含优化器状态。没有重新训练或改写权重。

已完成：选择性FP16矩阵计算＋其余FP32、CUDA Graph和相同人体特征精确复用。X2 SoC1上完整CANO→LIP→GP→原生物理32帧录制短测：

| 方案 | 中位 | p95 | 最大 | 超过33.33ms |
| --- | ---: | ---: | ---: | ---: |
| 历史CPU参考 | 129.32ms | 134.54ms | 139.03ms | 32/32 |
| 准确混合精度＋Graph | 30.19ms | 36.13ms | 37.08ms | 11/32 |
| 再复用相同人体特征 | **29.09ms** | **35.88ms** | **36.43ms** | **8/32** |

精确复用省掉32次重复FK/特征计算，完整姿态及根平移与未缓存版本逐位相同。相对CPU原参考最大关节角差0.073度/根0.515mm，通过预定一致性门；这些是参考计算差，不是真人精度。

GP神经网络另搬GPU数值通过，但未得到明确速度收益，暂不采用。更高构建搜索在600秒原上限停止，未生成engine，不扩大预算重跑。全FP16的约14度/3cm偏差版本被拒绝。

结论：已有明显加速和通过精度检查的候选，**尚未稳定30Hz**。平均耗时30.15ms的倒数约33Hz不能掩盖超时。当前仍是离线探针，未自动替换衣服实时入口；没有新BLE、反馈订阅、MC操作、电机命令或训练。

下一步：真实墙钟30Hz长序列＋Morph CPU 50Hz同机测试，分列帧队列年龄、p99/最大耗时、丢帧与内存/温度，再接入第一终端。180ms人体预览需求仍独立存在。
