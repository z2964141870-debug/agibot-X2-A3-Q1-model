## 当前判断

现象首先是**后期策略退化**，不足以认定为单纯训练集记忆导致的过拟合。约两小时的物理表现曾改善，最终熟悉的训练动作和独立验证一起恶化；不能把它解释为“只差更多训练”。也不能排除泛化问题并存，或据此确认世界模型利用、奖励投机、灾难性遗忘中的某一个已被证明。

WM误差来自训练小批量，不是独立保留集误差，更不是策略动作导数正确性的证明。想象存活率是模型内估计；接近1而真实走路跌倒，必须以真实仿真为准。这些分离信号提示优化目标或模型与实际控制的联系有问题，但还不能独立证明策略在“利用模型漏洞”。

## 优先核查的解释

1. 模型对状态预测较准，给策略的动作改进方向仍可能有偏；H32中误差与critic自举可能影响更新。需在相同真实状态上对照模型预测收益与物理收益，当前没有完成这一因果测试。
2. 当前合成tracking目标没有同时守住正常走路、上肢幅度及时序。最终共同前缀上肢关节误差约降10%，相对腕/腿/滑速/指令变化却恶化，支持多目标取舍失衡的担忧，不支持直接把奖励涨幅当任务成功。
3. 策略/critic更新幅度与动态replay覆盖可能导致已会步态被覆盖。当前日志不能分离更新过大、critic偏差、模型偏差和运动类别分布的贡献，不能宣布单一根因。
4. 传统泛化过拟合可能并存，但训练集本身也坏掉，单靠扩数据或dropout的方案缺少本轮依据。Q1控制/重定向仍是诊断维度，未因来源审计通过而被排除。

现有证据只能说“已会的走路在后期丢失”，尚不足以严谨定性为灾难性遗忘。RF12真实PPO也曾退步，因此也不能从RF14推导“换PPO即可解决”。
