# SuperMimic低延迟遥操探索

2026-11-05夜间开始，11月6日完成首轮源码审计、论文核验和离线外推比较。目标是降低遥操动作等待并保持自然性。本阶段没有训练、物理积分、GPU作业或真机实验；现有V04训练及原五阶段final门保持，用户采纳null。

## 当前判断

短期优先独立比较80-100ms真实预览、短预览加保守预测；长期优先学习只接收当前人体目标与历史的因果接口。预测200ms并不等于消除200ms误差，平滑也不能取代时间对齐。低层执行相位滞后和在线重定向同样应量测，不能把全部延迟归于未来帧。

保留SuperMimic世界模型和训练方法是可行的研究方向；改变的是部署接口能看到的信息，不必将世界模型整体替换。论文中的32步想象是训练梯度计算，不表示部署时等待32帧。是否能获得自然、稳定的Q1步态仍需实际闭环验证，当前训练后的低离地和滑移问题也尚未通过自然性验收。

## 三种压缩

| 做法 | 对等待的影响 | 主要问题 |
| --- | --- | --- |
| 保留前4/5个20ms目标 | 在本项目约定下，预览缓冲变80/100ms | 现有full权重未训练该条件，必须另测；尾部通过掩码隐藏 |
| 从200ms范围稀疏抽4/5帧 | 最远目标仍在200ms，等待不会减少 | 只降低采样密度；网络还需知道真实时间戳 |
| 把200ms动作挤进80/100ms执行 | 加速动作，不是单纯减延迟 | 2倍速度对应4倍加速度，接触/力矩需求变化；q、qd和旋转轨迹须一致 |

建议将“压成4-5帧”明确为缩短真实预览，或保留10个原时间槽并补预测尾部。不能用插值把时间含义悄悄改掉。

### 预测器

从保持姿态、常速度、阻尼常速度开始，再考虑小型GRU/TCN等因果预测器。训练目标先覆盖未来20-200ms完整轨迹，再分别报告各时距误差，不能只报十帧平均值。学习型预测还需按源片/动作/被试划分训练与留出数据，覆盖急停、反转、抬脚触地、异常感知和丢包。

保守预测可采用q_hat(h)=q_latest+v_hat*tau*(1-exp(-h/tau))；速度逐渐衰减，避免长期线性冲出去。本轮固定tau=.12s，并非已调优参数。进一步可用预测不确定度选择保持/阻尼外推/短掩码；原模型没有置信度通道，新增通道需新版本训练，不能塞进现有特征。

人体位置、旋转和关节参考要在一致的锚点和时间轴下生成；旋转在SO(3)上预测/插值，运动接口的qd应与q一致。支撑脚不能因预测而持续离地或移动。上肢更快、下肢更保守是新协调接口方向，现有可分离mask不能直接实现不同部位时间窗口，更不能把两段不同时间的全身目标生硬拼接。

### 因果学生

初始可以复用可用教师/解码器和物理动态，但学生只能读当前可得到的目标与历史；未来只供教师、critic或训练损失使用。结合学生自身状态采样、动作/latent对齐和真实任务回报，逐步减小预览。对不可预测的急停，不承诺提前知道，重点评价反应时间和稳定停止。当前教师本身还存在低离地/滑移，不能将其原样蒸馏视为自然性保证。

### 低层与滤波

ExtremControl的可借鉴形式为tau=Kp(q_target-q)-Kd*qdot+eta*Kd*qdot_target。其理想单关节分析中，低频相位延迟随(1-eta)减小；论文也强调离散控制周期限制过大的eta。实际Q1多体接触、饱和、延迟和执行器参数必须独立校准，此式不是当前可直接上线的修改。

滤波优先比较因果1 Euro、自适应截止频率和限速/限加速度，先测抖动-延迟曲线。普通因果5点均值在50Hz的低频群延迟为40ms；居中均值和零相位离线平滑还会读未来。不能用离线平滑后的曲线来宣称实时零延迟。滤波的相位和预测补偿应分别统计，避免相互抵消后掩盖过冲。

## 论文依据

只采用下列已打开核验的作者论文或官方页面；数字属于论文各自的G1/H1系统，不是本项目Q1结果。

- [SuperMimic，2026-10-20](https://arxiv.org/abs/2610.28480)：世界模型与策略联合训练、短想象梯度和可替换目标接口，为保留训练主干、另做部署接口提供结构依据。
- [HuMiT，2026-10-21，V-A/V-B](https://arxiv.org/html/2610.29903v1)：只使用当前帧紧凑目标，报告约20ms通信到策略输出、65ms视频法中位端到端延迟。其同前端比较SONIC 10帧/200ms缓冲为245ms端到端，4帧/80ms缓冲为145ms；表III同时显示部分数据集成功率下降。说明缓冲可减但存在跟踪代价，65ms也不是对Q1的保证。
- [OmniH2O，2024-06-13，3/4/附录C](https://arxiv.org/html/2406.08858v1)：特权教师蒸馏部署学生，利用历史处理部分可观测性；支持研究当前目标+历史的学生，不意味着历史能确定任意未来意图。
- [ExtremControl，2026-02-11，III/IV/VI](https://arxiv.org/html/2602.11321v1)：直接末端SE(3)目标、单未来帧学生、速度前馈及离散时间分析。需同时处理目标接口和执行响应，不能只截断预览。
- [1 Euro，CHI2012作者页面](https://gery.casiez.net/1euro/)：速度相关截止频率及抖动/滞后调参，适合作为因果滤波候选；仍需本系统时序实测。

## 后续对照与测量

按依赖顺序准备独立对照，不热改当前训练：

1. 先建立human/H10同物理基线，再仅改H5/H4/H2/H1；不能用motion/H10与human/H4直接归因预览长度。
2. 相同H4缓冲，比较mask尾部、保持尾部、阻尼预测尾部；各自记录可见/预测时间戳，禁止读取未来heading、速度或在线重定向的隐藏未来。
3. 在留出完整人体轨迹上评估学习型预测、脚接触约束和急停反转，再进入新版本因果学生训练；预览课程和空间点掩码分开控制。
4. 仿真验证之后，才独立检查执行速度前馈；原V04世界模型只覆盖既有动力学，控制器改变后须再验证或更新相应模型。
5. 最后用外部视频/运动传感测真实动作延迟，不能仅以encoder前向耗时替代。

软件时间戳分别覆盖采样、感知、映射/重定向、排队、预览缓冲、策略、下发与执行反馈；使用同步时钟或外部光学共同参考。报告p50/p95/p99、时间抖动、丢包与旧包年龄。稳定周期动作还需急停/随机反向事件验证，避免互相关对齐掩盖过冲或预测错误。

自然性同时记录完整率、足底离地/左右交替、支撑滑移、侧倾、手/脚/根误差、速度与加速度、动作突变及力矩饱和；延迟更低但急停滑移或抖动增大不算改善。本轮没有这些闭环新结果，未将离线预测误差换算成端到端延迟或自然性结论。
