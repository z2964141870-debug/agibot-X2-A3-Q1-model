## 本次讲解：评分权重与网络权重

官方环境以弧度记录杆角度，倾斜项默认系数为 `rew_scale_pole_pos = -1.0`。下面是单个环境的阅读简写，完整奖励还包含存活、失败与速度项：

```python
weight = 1.0  # 人设定的惩罚力度，本次训练期间固定
tilt_reward = -weight * pole_angle_rad ** 2
```

`** 2` 就是乘自己一次。例如倾斜 0.2 弧度，权重 1 时这一项是 −0.04 分；权重 3 时是 −0.12 分。左右同样幅度的倾斜扣分相同；角度翻倍时，这一项惩罚变成四倍。权重从 1 变 3 只放大倾斜项，不是把整个奖励乘三。

这里的 `weight` 是我们设定的评分规则。Actor/Critic 内部的权重和偏置，才是优化器在训练中更新的参数。修改评分规则不会立刻修改已经保存的 Actor；需要按新规则收集经历、训练，再评测新策略。更严的倾斜扣分也不保证最终更稳，可能影响探索与不同目标的取舍。

聊天中的交互图只计算给定姿态的单步倾斜分数，不模拟物理或训练效果。可恢复源码为 [pole-tilt-reward.html](../script/teaching/lesson02/pole-tilt-reward.html)，本次显示副本位于 Mac 的线程可视化目录。视觉检查包含默认宽度与 320 px，已确认权重 1→3、正负 0.2 rad 的输出变化。
