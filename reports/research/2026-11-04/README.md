1. **Koopman 世界模型：结构更规整，跟踪未必更好。** 作者在 SuperMimic 式 G1 跟踪中，把普通 MLP 换成“升维后尽量线性”的模型，希望更容易预测和求导。作者报告：最佳归一化回报 0.823 对 MLP 的 0.830，同数据一步误差反而为 1.3–1.6 倍、训练约慢 15%。效果最好的方案每步重新升维，已无法连续利用线性状态演化。对我们有用的是先看实际策略动作附近的预测误差和闭环跟踪，不因结构漂亮就换模型。**证据：原文方法、实验及结论相关段落；未核验代码或复现。** 论文来源未确认公开实现、权重或可取用资产；单一 G1 跟踪，模型参数量也不同，不能推出 Koopman 在其他控制问题都无用。**建议：只作背景，当前 MLP 基线保持。** [原论文](https://arxiv.org/abs/2611.00951v1)

2. **不确定性：会排风险高低，不等于知道会错多少。** 一项 RWM/RWM-U 复现发现，多个模型的分歧能把较难预测的轨迹排在前面，却严重低估绝对误差。作者报告：100 步预测的一倍标准差覆盖率仅 4.6%，高斯校准目标约为 68%；让各模型独立滚动后升至 33%，仍不能直接当误差区间。对 Q1 的启示是未来若用分歧惩罚奖励或调节想象长度，应先在留出的动作片段核对“声称的误差范围实际覆盖多少”，并和便宜的基线比较。**证据：摘要及正文方法、校准和局限相关段落；未核代码、未复现。** 作者称代码和工件随匿名补充材料提供，本次未确认公开可用包。只测一机器人、一种步态、一数据集，没训练策略，不能据此声称 Q1 策略会改善。**建议：基线完成后再试，不新增当前硬门。** [原论文](https://arxiv.org/abs/2611.02699v1)

3. **Anchor 1：精确保持手腕目标，需要独立看执行误差。** 它把校准后的稀疏人体目标编码为动作指令，再把“目标与当前机器人姿态差多少”单独送入控制器纠偏；部署不用在线关节重定向，训练仍使用离线整理的机器人参考。评测同时看精度、持续保持和可达性，正对应我们“完整跑完，但脚底滑、局部偏差仍大”的诊断，也与未来头环手腕控制相关。**证据：正文方法、反馈消融及局限相关段落；未核代码、未复现。** 本次原文未确认作者实现、权重或评测资产入口；仅验证一种本体，稀疏姿态不表示物体接触力或抓稳。**建议：现在理解评测维度，接口改造留到基线完成后。** [原论文](https://arxiv.org/abs/2611.00193v1)

4. **NablaMimic 0.2：比较结果必须锁定配方和评估策略。** 11 月 3 日代码更新让窗口内重置后的步继续参与目标，加入策略参数滑动平均，并把学习率预热从 500 改为 100 次更新；评测默认读平均策略。新 README 的“8 分钟到 0.82”是作者在 RTX PRO 6000 上的新配方报告，旧论文配方另存为 `ours_v1.args`。**证据：固定提交的训练、评估、配置、许可等 8 份文本及完整目录静态核验；未运行。** 代码 Apache-2.0，数据许可另算；默认约需 50GB 显存、G1 专用，所查完整树未见常用权重文件后缀，发行列表为空，未下载其他资产。**建议：现在记录版本差异，基线后再评估移植；不能把 8 分钟换算成 3090/Q1 耗时。** [作者代码](https://github.com/OamIcs/NablaMimic/tree/bfbb2a6773b4776c17402a34a93ec7589d9c7c18)
