## H001：异步观测下的历史信息使用

登记：2026-09-29。状态：**候选，未实现，未完成新颖性查证**。触发来源：[DRAM](https://arxiv.org/abs/2609.32453)、[已有 EgoLocate 分析](../EgoLocate与头环分析.md)。

### 问题与迁移边界

衣服身体观测与头环视觉手部观测异步，手部可遮挡，观测到达时可能已过期。希望历史信息能帮助恢复，但过期信息也可能使输出落后或突跳。

DRAM 说明固定大小的历史记忆已用于机器人操作。现有 Stage-A 也已有 30 帧因果 GRU、新鲜度门控和 FGP fallback。因此“记忆”“融合”“观测年龄输入”各自都不能预先宣称新颖。

候选改造是假设：按观测年龄、可靠性和恢复状态管理记忆更新/读取，在相同计算预算下减少过期观测污染。它是否不同于已有异步状态估计、循环策略和延迟补偿，需要正式检索后判断。先研究人体参考端，后续才考虑机器人接触约束。

### 最小实验和前置条件

1. 首先完成训练基线并检查数据条件：时间记录、坐标系、独立的手腕位置/姿态参考和动作覆盖。HaMeR 单目估计不能自行充当厘米级真值；主机读帧时间也不是曝光时刻。
2. 固定一批身体/手部同步记录，用站立状态的低幅手腕到达或轨迹任务回放。先统一额外注入 0/50/100/200 ms 延迟和若干遮挡时长；这些是实验设定，不是当前系统延迟实测值。
3. 比较纯 FGP、已有确定性 IK、简单滤波/时间补偿、可复现的 Stage-A，再加候选方法。Stage-A 的完整训练工程与权重尚缺，未补齐前不能虚构该对照结果。
4. 保持输入数据、数据划分、下游控制器和延迟预算一致；学习方法按录制会话或被试划分训练/测试，避免相邻帧泄漏，并用多个种子报告波动。
5. 消融观测年龄、可靠性、新的记忆更新规则。先报告离线手腕位置/旋转误差、遮挡恢复突跳、推理 P95/最大延迟；随后在固定仿真控制器上加触达成功率、关节约束与接触稳定性。离线更平滑不证明机器人更稳定。

### 否定条件与投入关口

- 简单时间补偿或现有门控 GRU 在同预算下已达到相同效果，则不值得仅为增加模型复杂度立项。
- 改善只出现在合成延迟或参与训练的会话，对真实记录/新动作不成立，则缩小结论并降低优先级。
- 手腕误差下降却显著增加响应延迟或使仿真接触更差，不能视为端到端改进。
- 发现等价先行工作，则转为复现基线或重新界定问题，不通过换名主张原创。

量化验收阈值应在获得基线分布后、正式比较前固定。当前缺少测量，不填造目标提升百分比。

### 进入实现前的查新清单

组合检索：`asynchronous multimodal fusion humanoid teleoperation`、`observation age recurrent policy latency`、`delay compensation visual inertial wrist tracking`、`uncertainty gated memory robot policy`，并查相关工作和后续引用。至少比较递归滤波/延迟状态估计、现有门控 GRU、机器人历史记忆三类工作。登记最相近方法与具体差异后再讨论创新强度。

本期只确认近期记忆方法及本地已有实现，未完成上述系统查新，也没有启动实验。

### 2026-09-30 先行工作补充：GAE

[GAE / General Action Expert](https://arxiv.org/abs/2609.34233) 已在全身遥操策略中显式加入延迟条件，并通过移动人体 token 的 RoPE 时间位置编码实现不同预测时间。正文报告了延迟补偿与精度之间的取舍，并包含 G1/O1 实验。核验层级为摘要、相关正文段落与作者项目页，未复现。

H001 继续保留为待验证问题，重点检查衣服/视觉各自延迟与可靠性变化、遮挡后旧观测更新的影响。与 GAE 的统一预测时间是否存在实质差别，还需完整正文和更多状态估计/融合先行工作支持。没有新增 H002，也没有把候选标为已确立创新。

### 2026-10-01 先行工作补充：T²Mem 与 DRAM v2

[T²Mem](https://arxiv.org/abs/2609.36720v1) 已将测试时自监督快权重更新用于机器人记忆：读取历史记忆形成动作预测，并按观测的自监督误差更新回合内记忆；新回合重置到学习到的初始化。已核验摘要、方法、相关工作、部分消融/限制和项目页，未复现；作者项目页代码仍标记 Coming Soon。

这说明 `test-time training`、`fast-weight memory`、`episodic memory` 不能被直接作为从语言模型迁入机器人的新点。论文相关工作还明确涉及 Active Neural SLAM、Scene Memory Transformer、循环策略、RoboTTT 等；本次仅通过该论文识别这些查新入口，没有独立复核它们的原论文。后续必须把这些同义词、异步状态估计与延迟观测更新一起检索，而非只查“LLM memory”。

本项目若考虑快权重，仍需具体说明：衣服与视觉的观测时间不同、遮挡后旧信息到达时，哪些更新应抑制或校正；并实测对手腕误差、恢复突跳和端到端延迟的影响。T²Mem 的操作任务与推理核时间不能证明解决了这一瓶颈；“加记忆”“按观测年龄门控”仍受现有 Stage-A GRU、新鲜度门控和 FGP fallback 的先行实现限制。

[DRAM v2](https://arxiv.org/abs/2609.32453v2) 相比 v1 新增 RMBench 九项双臂记忆任务。作者报告平均 57.8%，引用 Mem-0 为 42.0%；但每任务试验数和部分训练/评测流程不同，不能当作严格公平的算法胜出。新增结果支持把真正依赖历史的任务和记忆干预纳入实验设计，不能代替本项目异步传感器测试。版本更新于 9/29 UTC，10/1 首次核验差异。

在原有最小实验上，可将“读到正确历史／替换为其他会话历史／抑制记忆写入”作为未来诊断候选；这些是已存在的干预思路，不登记为新算法。先保留纯 FGP、简单时间补偿、现有 GRU 对照，确认收益来自有效历史而非数据泄漏或额外算力。没有数据、基线和实时测量前不进入实现。本次不新增假设、不调整训练主线，H001 仍为待验证。
