# X2 SONIC 衣服输入节拍离线回放

## Done

用 Mac 已存 ( `orin_real_active` 和 `orin_real_worn` ) 两段各 599 包的 FGP 人体记录，重放原有 SONIC 接入门控。原件为 `data/analysis/X2_ORIN_BASIC_20261113/data/analysis/{orin_real_active,orin_real_worn}/input_human.jsonl`。程序核对输入格式、标定和骨架标识稳定、序号和到达/捕获时间单调；年龄按原回放 **到达时间** 计算，未检查、转换或重跑姿态数值。两段原始最大到包间隔分别为 107.47 和 53.13 ms。

按 20 ms 控制周期重放。前 1 秒作为站立观察；操作者请求、上游参考、站立反馈与目标合法标志为夹具。模型头在请求变化后由夹具模拟固定 80 ms 确认。此 80 ms 为场景设定。分别对照 80、100 和 120 ms 三种年龄，以原序列和删除 5.00–5.30 秒之间到达帧的场景各跑一轮，共 12 种离线组合。

| 输入 | 120 ms、原序列 | 120 ms、注入 300 ms 到包中断 |
| --- | --- | --- |
| active，599 包 | 该 13.5 秒片段内无超龄撤权 | 删除 6 包，5.10 秒请求撤权，当时最后包年龄 135.67 ms |
| worn，599 包 | 该 13.5 秒片段内无超龄撤权 | 删除 9 包，5.12 秒请求撤权，当时最后包年龄 123.73 ms |

两段在 0.50 秒的过早接入都被拒绝，1.50 秒允许首次接入。注入断流后，人体包恢复但操作者尚未松开请求时，均无自动接回。5.66 秒的新请求仍被拒绝，7.50 秒在新请求与站立观察都满足时允许接回。12.50 秒操作者正常撤回，模拟头回到 planner。未注入的 active 在 80 和 100 ms 阈值下分别于 10.96 和 10.98 秒各触发一次超龄撤权，worn 无此现象。该敏感性来自实际保存的到包时间与指定事件脚本。

本轮只验证门控对已录输入节拍的反应。没有运行 tokenizer、策略头、板端、真实反馈或硬件，实际模型头样本为 0。现有现场已验证的 kplanner 不改，阈值未用于现行部署，没有据此确认真机切换或目标连续性。
