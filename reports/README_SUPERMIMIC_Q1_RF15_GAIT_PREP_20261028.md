# RF15普通走与原地上肢补偿准备

## 目标与范围

按用户晚间新目标，在RF14物理择优底座上做唯一新PPO补偿：最多14400实训秒，首约3500秒确认真实改善才延长。先普通走、抬脚、滑移、姿态与抬手全程稳定，根精确XY只作诊断。当前为准备，未启动RF15，RF14仍运行，不能同时再开训练/GPU预检。不开agent、不故障重试/续训清预算，不恢复旧RF13。

## 独立实现

新代码仅在`script/supermimic_q1_gait_comp/`，未改RF14冻结来源。使用已安装RSL-RL PPO核心、24×4096采集、5epoch×4minibatch、24576小批、lr1e-4/clip.2/gamma.99/lambda.95/grad1、std.1固定，前10轮仅新critic，计入预算。选定HP底座/归一化冻结；新256/128 ELU14维腿腰head，物理残差`.15*tanh(z)`rad。沿用原AP02 300/30、80历史×10/590目标、原控制/噪声/合法转移，新增15维足端位置/速度误差与参考支撑/静止状态，head总输入1420。BF16教师与FP32 head均固定4096前向块；概率FP32。

手臂采用75%参考/25%冻结教师确定性混合；训练重置25%概率保留alpha0，保护原底座情形，无启发式自动回退。物理评测另列纯底座、static075零head和学习后补偿，避免把参考混合自身收益算成学习。alpha075评价与RF13类似，但底座按RF14最后择优，新的foot条件与奖励独立。

## 奖励定义

保留底座原reward，另外每20ms实际转移：

| 项 | 权重与尺度 | 实际信号 |
|---|---|---|
| 支撑脚防滑 | +.02；滑速尺度.15m/s | 参考踝低于片内5%分位高度+.025m且参考XY速度<.2m/s时，实际原生受力>5N才获exp(-滑速平方) |
| 摆脚轨迹 | +.02；XY尺度.10m、Z尺度.04m | 参考踝抬高>=.025m时，heading骨盆相对XY与实际世界Z跟踪，两项指数均值 |
| 动作平顺 | -.002；目标变化尺度.10rad，平方均值上限25 | 本次与前次实际PD目标之差，22关节记录，只有腿腰head可学习 |
| 原地站稳 | +.01；XY速度.10m/s、角速度.50rad/s、重力方向.20 | 仅参考双支撑、根XY速度<.05m/s及角速度<.25rad/s的阶段奖励低实际速度/参考姿态误差 |
| 残差正则 | -.002；残差半径.15rad | 腿腰残差归一化平方均值 |

每项单独记录，总最大步奖励.15；负成本不伪装为旧reward改善。参考踝位置由相同Q1 FK获得，不声称是足底净空。接触读最后5ms求解子步且在自动重置前，不是20ms受力积分。所有奖励按s1和f+1对齐；静止定义不奖励站住来规避普通走。
