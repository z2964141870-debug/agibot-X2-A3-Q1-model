## 可持续使用的优化方法

1. **保留官方作为可回退基线。** 每个候选从固定权重和配置开始，训练计数与数据用途独立，不用坏模型接着盲训。
2. **明确一次只改善什么。** 以可靠动捕参考及实际目标动作定义指标，基准动作另用于保持能力；当前动捕尚未质量验收，官方20样例只提供工程诊断，不能替代遥操目标任务。
3. **用epochs1与约1e-6量级自适应步长作为候选起点。** 这是当前减少退化最好的已测试设置，不是最终最优超参；固定初始/上下界/数据/seed，2更新之后立即评测，记录全部指标和权重漂移。
4. **评测决定是否继续。** 工具输出官方非退化门槛和逐指标原因；无通过模型时自动选择官方作参考，仅生成选择记录，不发模型或操作机器人。新跌倒、根或基础能力退化时保存失败结论并回退。不能只因训练reward上涨、更新数增加、固定输入漂移小就继续长训。
5. **通过短筛选才扩大验证。** 增加独立seed与未用于挑方案的新动作/会话；出现可重复目标改善后，再分段延长并逐段检查，最后导出与独立仿真验收。

实际工具：`search_trial.py`提供独立训练/核验/评测/报告入口，`search_drift.py`提供CPU固定输入检查，`search_selection.py`汇总拒绝/保留原因。3项试验隔离/参数契约、3项选择门槛契约通过。选择工具本次结果`selected_reference=official`、`new_policy_improvement_found=false`，4个历史/新候选均未过门槛。这条实验流程可以持续复用；正向提升的方法尚未验证。
