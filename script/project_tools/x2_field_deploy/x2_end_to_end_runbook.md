# X2 键盘行走 —— 全流程终端命令单（从开机到收工）

> 在**桥接机**上运行（可直连机器人内网 10.0.1.x）。两个终端，都登 SoC1（Orin）。
> 现场前提：机器人在 rig 上悬吊、急停有人值守。
> 机器侧已修补 deploy 的停 MC 超时竞态（持久保存，重启不丢）。
> ⚠️ 纪律：**一个开机周期内只做一次"停 MC 接管"**；要重来就整机断电重启，不要连续重试仪式。

---

## 阶段 0 —— 开机（现场，学弟操作）

1. 电池装好，**长按电源键 5 秒**开机
2. **等约 90 秒**（厂商栈自启：em / hal / MC，别碰机器人）
3. 遥控器 **短按 L2 + X** → 位控站立
   - 机器人腿部绷紧到站姿 = 成功
   - 机器人瘫着 = 没切上，再按一次
4. ⚠️ **必须先站立再进阶段 1**，否则部署自检会拒发

---

## 阶段 1 —— 启动部署（终端 A）

```bash
ssh agi@10.0.1.41
# 密码 1
bash ~/gear-sonic/ritual_start_kb.sh
```

看输出：

- `pose stream OK (4220b)` = 启动成功（约 1 分钟）
- 若 `FATAL: kplanner ...` = 等 30 秒，重跑一次命令
- 还不行 = 停，叫远程

然后接着在这个终端看部署接管：

```bash
tmux attach -t x2_deploy
```

依次看到（约 30 秒内）：

| 看到什么 | 含义 |
|---|---|
| `Preflight PASS` | 自检通过 |
| `stopping MC via ...` | 正在停 MC（机器人**轻微下沉一下，正常**，rig 兜底）|
| `CONTROL tick=...` 每秒刷新 | ✅ 策略已接管，可以去走了 |

退出监视（不退出部署）：`Ctrl-B` 然后 `D`

⚠️ 若 `Preflight FAILED`：确认机器人是否站立 → 重跑阶段 1 一次 → 再败叫远程

---

## 阶段 2 —— 行走控制（终端 B = 键盘）

**终端 B（新开一个）：**

```bash
ssh agi@10.0.1.41
# 密码 1
~/walk/t2_keyboard.sh
```

看到 `PUB->tcp://127.0.0.1:5563/planner-cmd` 后按键：

| 键 | 动作 |
|---|---|
| `w` | 前进 0.35 m/s（**按一下锁定，持续走**）|
| `空格` | **停** |
| `a` / `d` | 左转 / 右转 0.65 rad/s |
| `s` | 后退 0.1 m/s |
| `q` | 退出键盘工具（自动缓停）|

⚠️ 每按一下必须有回显 `cmd vx=...` 才算发出

**第一次建议**：`w` 走几秒 → `空格` → 看状态 → 再来

---

## 阶段 2+ —— 监视（可选，终端 A 复用）

**看策略心跳（终端 A 复用）：**

```bash
tmux attach -t x2_deploy
```

- `CONTROL tick` 每秒刷新 = 正常
- `pose_ref_age` 从 `-1.000` 变活值 = 你的按键已进链路
- `act_clip=0` = 无饱和

退出监视：`Ctrl-B` 然后 `D`

---

## 阶段 3 —— 收工（走完了）

1. 终端 B：`空格` 停 → `q` 退键盘工具
2. 终端 A：

```bash
tmux attach -t x2_deploy
```

   按 **`Ctrl-C`**（就一次），然后看它自己完成交接：

| 看到什么 | 含义 |
|---|---|
| `RAMP_OUT` | 策略缓出 |
| `start_app` `SetMcAction ... STAND_DEFAULT` | MC 回岗、机器人回到力控站立 |
| deploy 干净退出 | ✅ 收工完成 |

3. 机器人回到 MC 站立后，现场按官方流程关机（遥控器让机器人趴下调零力矩，再断电）

---

## 异常对照表

| 现象 | 动作 |
|---|---|
| 机器人动作异常 | `空格` → 不行就急停 |
| `CONTROL tick` 不刷新了 | 急停，叫远程 |
| 键盘回显没了 / 工具死了 | 急停，叫远程 |
| 阶段 1 preflight 失败 | 确认站立 → 重跑一次 → 再败**整机断电重启**（别连试）|
| 阶段 1 kplanner FATAL | 等 30 秒重跑一次 |
| 停 MC 卡住不动 | 急停，叫远程 |
| 重跑仪式超过 1 次仍异常 | **整机断电重启再来**（MC 停/启反复会触发 DDS 传输卡死，这是下午"数据消失"的根因）|

## 安全总顺序

**软停 `空格` → 退工具 `q` → Ctrl-C 交接 MC → 物理急停（现场最终裁量）**
