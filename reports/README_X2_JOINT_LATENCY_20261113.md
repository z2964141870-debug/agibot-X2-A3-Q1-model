# X2 FGP 与 Morph 联合延迟测试

日期：2026-11-13。当前阶段：JOINT_R3_R4_COMPLETED。真实同机录制输入与机器人反馈静默联合测试、保存分析完成；尚未满足30Hz，不做电机输出。

结论：按作者“取最新帧”方式，计入180ms预览跨度，后端目标对应的最老人体参考年龄中位保守范围为296.93–310.46ms，p95为341.15–356.36ms。实际人体更新17.805Hz，尚未30Hz；不能把它称为真人动作到电机响应的端到端实测。

## 目标与边界

在 SoC1 同机运行准确的 S1 mixed_gemm TensorRT＋CUDA Graph＋精确特征复用、原始 LIP/GP/原生物理、原始 CPU Morph human 策略及现有 C++ observe 后端。衣服输入为已有真人录制 IMU，不连接 BLE；机器人反馈为只读 ROS，实际 SDK 发布、电机命令、MC 修改和训练均为零。原实时衣服入口、第二第三终端源码和 Q1 暂停训练不改。

截取 manual_full_test_001 连续929帧与原标定，按理想30Hz墙钟释放，29帧历史后900次真实FGP输出。不是循环61帧、离线无节拍吞吐或BLE原始抖动测试。FIFO保留全部输入，直接记录过载积压；这只是本次测量队列策略，不能当成已经部署的实时衣服队列。Morph和原后端以50Hz尽力调度，20ms接受边界保持。

## 计时定义

- 输入排队：本机计划释放IMU时刻到FGP实际开始。
- FGP：标定、CANO、LIP、GP及原生物理。
- HumanFrame：坐标/骨架转换和本机ZMQ到达。
- 策略：真实反馈→CPU Morph→原生建议目标的实际RPC和后端接受情况。
- 人体参考年龄：同一本机monotonic时钟下，目标生成时刻减十槽最老capture。原180ms预览跨度只计一次；另列最新槽和最新原始支持年龄，不冒充所有输入都是180ms旧。
- 原native日志不含接收绝对时刻，因此服务生成时年龄是下界，另加该请求全RPC给保守上界，不伪报精确writer接收年龄。

没有衣服传感器采样/蓝牙无线时延、动作相位GT或真实机械响应；物理端到端延迟保持null。约30秒录制输入不能认证自然遥操或长期稳定性。

## FIFO 首轮实测与新鲜度补测

R1缺ZMQ在FGP初始化前退出；R2包装器把作者初始化stdout误作JSON导致退出，仅发生graph初始化。两失败根保留，均无真实FGP帧/后端输出。R3真实929输入/900输出、2601反馈请求/2479 ready/2232接受，GPU900次；247次RPC超过原20ms拒绝，122次人体尚未就绪。FGP中位42.225/p95 66.225ms，转换4.490ms中位/人体RPC5.608ms中位，实际人体输出17.647Hz。FIFO末尾积压20.963秒，参考年龄中位10.988秒；不能把该诊断队列说成作者实际入口或固定硬件时延。

已查作者`online_fgp+LIP_realtime_onnx.py:732`实际明确取最新传感器值、不排空积压。因此独立R4追加一次latest-wins新鲜度测量，复用原929帧释放时钟/模型/反馈后端，100秒总门及最多900FGP上限，不重做R3。处理完成后丢弃已经过时、尚未进入FGP的原始帧，并逐件记录丢弃数、真实输出频率和参考年龄。该取帧方式贴合作者在线入口，但模型及原生物理仍为30Hz固定步长；过载跳帧的动态/姿态精度未验证，不能用低参考年龄掩盖低输出率。原实时入口不切换。

## R4 联合结果

37.122894秒含初始化；929个计划源帧中实际处理566、跳过363，29帧历史后537次真实完整FGP输出、537次重复特征命中。原生后端1566次真实反馈请求，1456次ready、1322次接受；133次超过20ms拒绝、1次反馈过期拒绝，110次人体参考未就绪。全部接受项都保留；不只汇报接受子集的低耗时。

上/下界不是置信区间：原native日志没有接收绝对时间，取服务回复就绪年龄为下界，再加该次完整native RPC为保守上界，其中部分计算被重复计入上界。以同一组逐请求上下界分别取分位数；不把几个阶段的p95相加伪造全链p95。参考年龄也不是已测动作相位误差。

FGP实际输出间隔中位54.775/p95 77.235ms、17.805Hz；512/537次FGP计算超过33.33ms，所有536个完整输出间隔超过33.33ms。Morph ready约48.516Hz，但有效接受间隔中位20.508/p95 44.713ms，仍有长尾；约50Hz的策略请求不会增加约18Hz的人体新信息。首个人体参考策略输出距源开始1251.562ms，包含30帧FGP历史及预览初始填充，须与稳定段年龄分开。末尾最大值包含有限录制结束后的继续采样，完整保留。

两组不是随机同输入开关Morph的因果对照，且长输入不同于此前32帧，因此不能仅据29→42ms断定全部变化由GPU竞争造成。当前分工为CANO GPU、FGP其他阶段及Morph CPU；尚未单独定位CPU线程、ROS、同步通信及功耗调度的贡献。
