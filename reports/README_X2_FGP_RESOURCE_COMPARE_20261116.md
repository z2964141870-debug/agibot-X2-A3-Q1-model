# X2 FGP 独跑与策略并跑资源对照

## Done

同一 Orin 上按独跑、并跑、并跑、独跑各跑 240 个录制 IMU。保留 GPU CANO、CPU 重建子进程、发送线程和两个在途帧。独跑时保留相同人体入库与 ACK，只省去 MorphMimic 的 CPU ONNX 和 50 Hz 状态请求。并跑使用 2 线程和固定合成反馈。每轮 211 输出、零跳帧。四轮 FGP 最大姿态分量差 5.96e-7、根平移差 2.24e-7 m。整机遥测按 500 ms 记录，每轮有效输出区间 14 个样本，CPU 值是每核中位、GPU 值是板级活动中位；无逐算子或所属进程 GPU 利用率。

并跑组的 GPU 活动最高一个样本 89%，CPU 最高单核采样 76%，GPU 温度四轮峰值 64.75–65.28°C。500 ms 采样未见持续满载，无法排除毫秒级热点、带宽竞争或温控。CPU 4、5 对应 FGP CPU 子进程配置，计数仍是整机，不能断定竞争线程身份。

单独运行仍有 177/420 个间隔超过 33.33 ms，并跑为 185/420。按不低于 40 ms 分组，独跑两轮有 23 和 53 个长间隔，并跑两轮有 41 和 38 个，轮间波动明显。CANO 主机调用为最大增量的数量，独跑为 0 和 20，并跑为 3 和 11。GPU Graph 流时间的波动在独跑也可出现。现有数据支持策略并跑增加下游确认压力和部分核的使用，不能把 FGP 长尾主要归因于策略造成的整机算力耗尽。

主机 `sched_schedstats` 当前为关闭，本轮未改变系统。板端回放退出 0，锁已释放，无遗留测试进程，未发电机命令。聚合结果和逐帧归因统计均从板端核对 SHA-256。遥测及原件在 `/tmp/x2-fgp-resources.Glk9Xq`。
