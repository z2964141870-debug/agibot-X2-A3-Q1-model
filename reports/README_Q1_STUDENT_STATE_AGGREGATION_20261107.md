## 为什么选择这一步

原R2仅复用教师实际状态，学生执行后偏离的状态没有进入该数据。新实验检验这项覆盖差异，未预先证明它是失败的唯一原因。七例失败都晚于历史槽填满且fallback为0，因此不将起步历史不足或缺包保持当成已确认解释。原R20/7与软件worker约31ms超期分别记录；固定步长顺序仿真的倒地不直接归因于真实时钟超期。

GigaBrain下一状态/接触辅助预测仍保留为后续独立消融。先建立学生状态适配对照，避免把采样变化与辅助损失变化混在一起后无法解释结果。
