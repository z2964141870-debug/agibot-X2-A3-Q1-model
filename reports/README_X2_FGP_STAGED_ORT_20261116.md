# X2 Orin FGP 分阶段与 MorphMimic 线程对照

## Done

在 SoC1 从 SHA-256 匹配的原 R3 源码生成独立回放入口，沿用 GPU CANO、原生 CPU 重建子进程、发送线程和最多两帧在途。固定释放同一 240 帧录制 IMU，按 4、2、2、4 个 MorphMimic ORT 线程跑四轮。每轮输出 211 帧，分阶段探针零跳过，CPU 子进程均以 0 退出且预览锁已释放。所有就绪参考沿用原 180 ms 窗口与真实到达截止检查。使用原模型和物理核、固定合成反馈及共享 ZMQ 回环，未发布电机命令。四轮 FGP 数值最大姿态分量差 5.96e-7，最大根平移分量差 2.98e-7 m。

两种线程配置的平均出帧都接近录制释放率，早晚阶段参考到达年龄没有累积漂移。这与先前只分离发送线程的保序探针表现不同。该前后对照中也变动了执行结构与绑核，多个因素不能分离定量。2 线程稳定改善状态 RPC 和源确认，FGP 间隔 P95 没有一致改善。2 线程两轮 420 个间隔仍有 185 个超过 33.33 ms，故本轮没有通过稳定 30 Hz 的间隔目标。参考年龄是录制源代理时钟到本机取窗的量，不含真实 BLE 或机械延迟。

板端 SHA 校验、进程回收及结果原件路径 `/tmp/x2-fgp-staged-ort.9AOV57/run/result.json` 已确认。构建脚本生成临时源，原 R3 和已安装入口没有改动。
