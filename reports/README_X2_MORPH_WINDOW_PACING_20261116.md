# X2 MorphMimic 参考窗推进离线对照

## SONIC 现场基线

用户确认，现有 SONIC kplanner 在现场测试中表现完美。把这套启动方式、模型和配置作为站立基线，后续先用 kplanner 站稳，再进入 tracking。验证重点是 tracking 人体输入、切换时的模型头和动作连续性，以及退出时回到 kplanner。旧备用站立片段和影子回放仅用于解释相应记录，现场基线以用户确认的实测为准。

## MorphMimic 回放

在 SoC1 对同一只读录制的 876 个就绪策略周期进行 CPU 回放。模型、关节映射、反馈张量、前序动作历史及 10 槽、180 ms 参考窗保持原样。候选只限制窗口末端每个相邻就绪周期最多推进 20 或 40 ms，使用对应时刻已到达且保存的支持帧。遇到就绪序号断开或标定、对齐 epoch 变化时，以该段首个可用窗口重新锚定。原路重建的人体特征及目标与存档差值均为 0。

严格 20 ms 方案积压明显，排除。40 ms 允许追赶，代价仍为最高额外 60 ms，右肘事件保留 15.03° 步长，暂不采用。两种方案使用原录制的动作历史，评价的是窗口变化对当前模型目标的影响。额外参考年龄来自源捕获代理时钟，未计真实 BLE 或机械执行。相对原目标的偏差也没有人体真值或跟随误差的含义。零电机命令，现场未重跑。
