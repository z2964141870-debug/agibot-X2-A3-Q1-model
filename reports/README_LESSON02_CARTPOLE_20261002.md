# 第二课：一次实际 PPO 训练、保存与重载

记录日期：2026-10-02（北京时间）。实验：`lesson02_cartpole_20261002_E002`。状态：Agent 已完成 Isaac Lab 倒立摆教学训练与独立进程重载；学员尚未独立操作，X2 训练仍未完成。

## 目标与任务

用户同意实践先行。本轮使用已安装的 Isaac Lab 官方 `Isaac-Cartpole-Direct-v0` 与 RSL-RL PPO，跑完采集、参数更新、保存、重新加载和评测。任务是左右推小车，使上面的杆维持竖直；这是带物理仿真的简单控制任务，不是 X2 或人体动作跟踪。

本课先看三件事：网络读入什么、输出什么、训练后行为有没有变化。当前不要求手推 PPO/GAE。

| 项目 | 实际接口 |
| --- | --- |
| 观测 | 杆角度、杆角速度、小车位置、小车速度，顺序固定，4 个数 |
| 动作 | 1 个连续数；环境将其乘以 100 N 作为小车关节推力目标，执行器还有力限幅/阻尼 |
| 奖励 | 保持任务得分，倒下/出界扣分，偏离竖直和过快运动扣分；使用原任务定义 |
| 结束 | 小车超出 ±3 m 或杆倾斜超过 ±90° 为失败；回合有约 5 秒时限 |
| 策略 | Actor 为 4→32→32→1 的小网络，Critic 也是 4→32→32→1；本任务二者看到同一组观测 |

环境先让策略尝试，记录观测、动作、奖励等经历；PPO 使用这些经历更新两个网络，再重新采集。没有人工标注的正确推力。这里输入是数字，不需要图像数据集。

## 完成内容与实际结果

- 仿真在 hp3090 的 RTX 3090 启动成功。1024 个并行环境，训练种子 42，150 次采集/更新循环，每个环境每次采集 16 步，共 2,457,600 条转移。
- 使用原 PPO 配方：每批数据 5 个 epoch、4 个 minibatch，Actor/Critic 两层 32 维隐藏层；未改奖励或重新实现 PPO。
- 固定评估种子 10001，训练前、训练后和另一个进程重载后，使用哈希相同的 1024 个初始观测。每个环境只统计重置后的第一个完整回合，包含所有提前失败；后续自动重置回合不纳入统计。
- 评测使用 Actor 的确定性均值动作，不更新参数。此评测集合用于教学前后比较，不代表跨机器人或分布外泛化结果。

| 指标 | 训练前 | 训练后 | 独立进程重载后 |
| --- | ---: | ---: | ---: |
| 平均维持时间 | 0.6446 s | 4.9833 s | 4.9833 s |
| 未失败到回合上限的比例 | 0 / 1024 | 1024 / 1024 | 1024 / 1024 |
| 平均回合回报 | 9.0969 | 296.7772 | 296.7772 |

任务配置时限为 5 秒，当前实现实际在第 299 个控制步触发时限；控制周期为 1/60 秒，所以应报告 4.9833 秒，而不是测得无限站稳。

Actor 与 Critic 各有 6 个参数张量发生更新，最大绝对变化分别为 2.073362 和 1.504162。保存后在新进程加载 `final.pt`，固定观测探针的最大动作差为 0；上述评测均值和成功率也一致。学习是否发生以参数差异为证据，控制是否改善另看新执行结果。

只有一个训练随机种子。1024 个评测回合不能代替多个独立训练种子；没有扰动、延迟、遮挡或人形机器人评测，不能用于宣称科研改进或智元模型训练完成。
