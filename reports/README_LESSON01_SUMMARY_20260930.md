## 完成内容：用同一个例子串起来

假设机器人处于某个姿态。这里用完整回合、不打折的教学例子，不把它当作全部实际 PPO 配置。

| 环节 | 例子 | 在学习中的作用 |
| --- | --- | --- |
| 当前观测 | 关节角度、速度、机身姿态等 | 描述当前可获得的情况；只看角度可能无法区分运动方向 |
| Actor | 根据观测给出动作分布，再采样一个控制动作 | 决定怎样行动；动作输出发生变化本身不证明网络已经学习 |
| Critic | 同一时刻预测，沿当前策略继续行动的平均累计回报为 10 | 提供对当前处境通常表现的估计；并非已知道未来 |
| 环境与回报 | 动作执行后记录奖励，假设为 4、5、5，累计得到 14 | 14 是这次实际经历的结果，不是 Actor 输出的预测 |
| 简化优势 | 14 − 10 = +4 | 表示这次经历高于原先预期，为策略更新提供一个学习信号 |
| 训练 Actor | 在同样观测下，倾向提高本次采样动作的概率 | 朝提高期望回报的方向改进动作选择；受 PPO 裁剪等实际因素影响 |
| 训练 Critic | 对这条样本，减小预测值与回报目标 14 的误差 | 用经历改善回报预测；跨许多经历学习条件期望 |
| 参数更新与再采集 | 计算损失、反向传播、执行优化器更新，再用更新后的策略采集 | 只有算奖励或梯度还不等于权重已经更新；最终要检查行为与评测 |

**这份经历同时服务两个目标：Actor 学会更好地行动，Critic 学会更准确地预测。整体任务是让机器人表现改善。** Critic 预测准确是辅助策略学习的重要手段，不是机器人训练唯一的最终目标。

## 最新复述需要补准的地方

### Critic 根据什么预测

本节的 PPO Critic 输入当时的观测/状态信息，预测沿 Actor 当前策略继续行动的平均回报；不需要先把这次待执行的具体动作作为单独输入。它从 Actor 产生的许多经历中学会当前策略通常的表现。某些观测可以含历史动作，不能因此混淆为直接评价本次待执行动作。

Actor 与 Critic 可以看相同观测。某些机器人训练给 Critic 更多仿真状态，是一种配置选择；更多当前信息仍不等于知道未来，预测数字更大也不等于更准确。

### 一次向 14 调整，不等于永远以 14 为目标

- 对本次样本，预测 10、回报目标 14，基础平方误差给出向 14 调整的信号。
- 若固定当前策略，在相同情况下长期回报稳定约为 14，预测应逐渐靠近 14。
- 若在相同情况下回报等概率为 6、14，正确的平均预测是 10；这时一次得到 14 不能证明预测 10 错了。
- Actor 改变后，其能够取得的平均回报也可能变化，Critic 需要继续从新经历学习。

这些是手算示意，不保证一次网络更新就按上述数值变化，也不把样本回报当成精确已知的期望。

## 已讲过的关键区别

| 容易混淆的点 | 本阶段应保留的认识 |
| --- | --- |
| reward 与 return | reward 是每一步的奖励；return 是从某时刻开始的累计回报，实际任务常考虑折扣 |
| 动作幅度与动作概率 | 学习更常选择某个动作，不等于把关节角度直接加大 |
| 好于预期与坏于预期 | 简化正优势倾向增加该采样动作概率，负优势倾向减少；不是只看绝对分数正负 |
| clip 与奖励正确性 | clip 调整优化激励，不能修复奖励漏洞，也不是筛掉失败样本的关卡 |
| 裁剪平台与停止学习 | 固定正优势 +4 时，策略目标可在 4.8 进入平台；不是概率硬上限，也不等于 Critic 或整批数据都不再学习 |
| 同批更新与重新采集 | 同批重复更新保持采集时的旧概率；重新采集才保存新的参考概率；4.8 不是跨轮必须增长的性能成绩 |
