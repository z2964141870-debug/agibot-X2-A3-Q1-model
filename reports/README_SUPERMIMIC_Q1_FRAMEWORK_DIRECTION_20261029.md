## 两条线如何区分收益

| 配对比较 | 要区分的收益 |
| --- | --- |
| 原底座与改进底座，均不额外适配 | SuperMimic底座本身的变化 |
| 同一底座，原适配与改进适配 | PPO或残差方法的额外收益与代价 |
| 同一适配方法，原底座与改进底座 | 底座变化对后续适配效果的影响 |
| 组合策略与对应未适配底座 | 最终系统的实际净增益，不能用两份独立收益相加替代 |

比较需尽量匹配控制、输入参考、固定片、评测重复和训练预算，并明确保留不匹配项。优先看真实前进、连续换脚、实际脚底离地、承重滑移、姿态、上肢幅度/时序及全程稳定，根XY继续诊断。该表是后续设计的归因结构，不是本次新增的训练清单或自动预算。
