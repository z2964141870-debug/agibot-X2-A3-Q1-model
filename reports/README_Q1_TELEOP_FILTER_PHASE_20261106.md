## 目的与方法

[因果重采样固定回放](README_Q1_CAUSAL_RESAMPLER_20261106.md)显示保持/外推/缓冲有不同连续性代价。此阶段仅使用预先定义的解析标量弧度信号，区分滤波相位、急停残余运动、反向响应和变化率限制。两段真人TEST_ONLY包不参与，不拟合模型或选择部署参数，也不将标量逐轴处理当作完整SO(3)/接触方案。

固定六方法：原值、因果5点均值、One Euro mincutoff=1Hz/beta=0、同1Hz/beta=.1、2rad/s变化率限制、beta=.1后串联同限速。导数截止1Hz、输入50Hz；参数不是在真人数据上调过的最佳值。

固定九场景：0.5rad阶跃、1rad/s坡道后急停、1rad/s反向、单采样0.5rad离群点、静止std=.01rad噪声seed42，以及.5/1/2/5Hz幅值.25rad正弦。记录每方法的50/90%响应、急停残余位移、首次反向与原始输入的额外等待、静止抖动、正弦基频增益/相位与谐波残差。

正弦相位是特定频率响应，不是端到端机器人延迟；自适应滤波非线性，因此同时报谐波残差，不能以一个群延迟代表所有动作。所有动态方法按单向时戳递推，超过200ms缺口拒绝续用旧滤波状态，由调用方明确回退后另开段。变化率限制不等于加速度/力矩限制，重开段也不保证与此前执行目标连续。
