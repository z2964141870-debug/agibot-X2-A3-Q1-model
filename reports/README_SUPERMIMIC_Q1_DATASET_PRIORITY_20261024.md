# PHUMA、BONES-SEED与AMASS的当前价值判断

记录日期：2026-10-24，北京时间。阶段：SM-Q1-DATA-CHOICE01。状态：原始来源与本项目证据复核完成；这是选型建议，不是用户确认的新训练配置，未切换或启动实验。

## 目标与结论

用户询问三种数据哪个值得优先使用。目标仍为SuperMimic世界模型方法复现并训练Q1全身移动跟随。按当前Q1适配问题和已到位资源，建议新增准备优先AMASS的小型移动子集；BONES-SEED作为后续对齐原论文的数据主库；PHUMA保留已准备参考及基线。该顺序不是三库在Q1上的已测性能排名。

严格对齐原论文训练来源时BONES-SEED第一；下一次无需新数据处理、尽快运行现成训练闭环时PHUMA成本最低。选择AMASS优先指新增数据准备和Q1映射诊断的投入，不把可立即启动PHUMA与尚待转换AMASS混成同一就绪状态。

AMASS直接映射的好处是控制映射变量，不能据此保证比PHUMA/BONES具有更好的物理可行性或策略效果。作者PHUMA结果在G1/H1-2上的收益不能当作Q1证据，亦不能忽略其对AMASS的原实验优势。三源真实比较须经同一Q1映射/准入与相当的动作覆盖、交互预算；不同源可能重叠，不能直接相加时长或跨源随机分片造成泄漏。

## 建议的验证顺序

1. 从AMASS选择10至20条平地慢走、正常走、转向、起停和侧移候选；这是待执行范围，不是已有合格动作数。记录原形体、真实120Hz、原速度与根轨迹，独立生成Q1参考并检查支撑、滑脚、限位、碰撞和所需驱动力，不以人体FK通过代替Q1准入。
2. 先确认少量合格移动参考在现有世界模型方法下可学，保留PHUMA已有结果及扩量库。比较时固定算法、奖励、评测语义及在线控制转移预算；动作类别和难度尽量匹配，另记数据处理和训练成本，不把多项变化归因于数据集单项。
3. BONES完整动作包核验后，优先接其移动子集，再逐步扩库，对齐原论文的数据覆盖。原库中的交互动作、镜像与重复必须另查；不要求先下载/转换全部数百小时才能检查Q1适配。

参考动作与世界模型训练转移仍是两类数据：SuperMimic用参考规定跟随目标，动力学监督来自在线模拟器的状态/动作/下一状态。换源不能替代Q1接触模型、在线覆盖与多步根预测质量检查。本轮没有新转换、物理步或optimizer更新。
