对同两份独立 FGP 录制（`orin_real_active`、`orin_real_worn`）分别按原样与中点删八包重播。Mac 使用原 CPU ONNX 策略和固定合成 X2 反馈。回看每个断流边界，取得断前末条和恢复首条的 ONNX 输入，然后交叉互换人体输入组与观测历史。两组原输入分别逐值复现原目标。观测历史内的关节、角速度与重力等反馈分量逐值相同，观察到变化的部分来自策略上一动作历史。四种回放均未在原断流区间生成建议目标或运行 ONNX。

表中列后三个角度是各边界同一个关节相对断前最后目标的带符号变化。删八包回放也复现了两个 active 原始边界。28.33° 左肘事件的联合交互项为 −0.0035°。恢复时最新人体包到达年龄为 15.45 ms，参考窗已跨过 320 ms。连续再跑五个周期后，左肘仍较断前目标高 26.48°，恢复后紧接的一步在所有关节中的最大变化为 5.09°。因此这次主要变化发生在退出断流时选入新的参考，其持续了多个周期。断流越长也不一定跳得越大。

28.33° 衡量的是两条策略建议的差。此事件断前左肘目标 −84.53°，恢复首条 −56.20°，固定合成反馈为 −34.38°。恢复首条在这个台架测量坐标中朝反馈靠近。实际机器人断流时的反馈与执行目标均未参与，因此断前建议或合成反馈不能直接充当下一次现场恢复的锚点。本轮没有接设备、运行执行器或更改部署。Mac 的 19 项 runtime 测试通过。
