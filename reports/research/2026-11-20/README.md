**本期重点：缩短训练时间、降低预测误差、做好真实控制，分别看证据。** 上次成功检查是 11/15，本次补查近七天，主要覆盖 11/16–20 公告；下面不是四项“今日首发”。最新 Q1 保存记录已进入 H002/H003 仿真和控制权交还，不能继续套用旧暂停摘要。SONIC kplanner 保留为用户已验证的现场站立基线。

## 1. XMimic/XSoma：先拆计算链，再看“不到一分钟”

[11/16 新稿](https://arxiv.org/html/2611.20452v1)把 SuperMimic 式的“采集→学模型→学策略”整轮编译，缩短串行小算子链，再分配给多张 GPU 并行。XSoma 只让网络学机器人动力学，奖励、终止和脚下地形查询仍按任务定义计算；约一秒的想象窗口让它可以不用 critic。

作者报告 G1、40 条 LAFAN1，在四张 H100 上 0.86 分钟达到跟踪门；**不含启动、编译和训练后评测**。单卡提升约 1.3 倍，四卡墙钟加速付出了略多总 GPU 时间，且尚无真机结果。**现在读计时分解，基线后再考虑实现。** 方法与实验正文、固定 README 已读；两库公开，XSoma MIT 许可正文已核，XMimic README 声明 MIT 但 LICENSE 补取失败；模型/数据未下载、未复现，LAFAN1 衍生资产另受非商用限制。

同时核到 [SuperMimic 作者源码 11/16–19 变化](https://github.com/HybridRobotics/supermimic/tree/698ea39bc901d8fe733b3c8621df3199d241f7e4)：删除采集时额外动作噪声、CUDA 下动力学/想象 actor 矩阵乘改用 bfloat16、整理世界模型环境与起点采样。新旧快照源码已静态对读；没有据此验证提速，也没有改当前工程。

## 2. 学习仿真器审计：一步准，仍可能学出不会走的策略

[11/17 审计原文](https://arxiv.org/html/2611.23118v1)让模型连续吃自己的预测，而不是每步都喂真实状态，再把学到的策略放进物理仿真。作者报告：18 个微调模型都改善了一步和八步误差，但其中 13 个产生失败策略；模型集之间意见分歧虽能排列风险，却不能直接当成已校准的概率置信区间。

**现在用于 H002/H003 的评测解释：拟合、多步漂移、闭环成功分别报告。** 它不证明当前 Q1 失败原因，也不增加实验门槛。方法、主要结果和否定结论已读；代码仓库公开性已核，模型包入口超时，未复现。范围仅 ANYmal D、单一步态、仿真；作者手工搭建的物理模型没有真机校验，部分预登记结论仍未解决。

## 3. MOSAIC：把“传感器装在哪里”作为独立估计问题

[11/17 的 Wear and Go](https://arxiv.org/html/2611.22894v1)从普通运动中累计证据，判断六个 IMU 各属哪个身体部位、安装旋转是多少，再校正输入给冻结的姿态网络。对衣服链路的启发是把安装误差与姿态网络误差拆开诊断，保留现有模型做对照。

**基线完成后再试。** 原文与[作者页](https://tanyuanshuo.github.io/wearandgo_page/)已读，代码标为 coming soon，权重未核。它假设六个指定部位和恒定安装偏移，尚未处理松绑带、衣服滑动；评测还替换了腕/手等关节真值，不能用来声称手腕精度。会话累计标定也不等于瞬间收敛。记忆、融合或累计证据本身不作原创贡献。

## 4. WinDEX：头环看手，要同时量头部运动和手部误差

[11/16 的 WinDEX](https://arxiv.org/html/2611.21143v1)结合标定双目、同钟 IMU、视觉惯性定位与手部网络，将腕部轨迹转到世界坐标，减少头动对遥操的干扰，并用独立光学动捕评测。与项目头环的手/腕控制、对时和 SLAM 直接相关。

**基线完成后借鉴评测与接口。** 已读部分方法、实验、局限和[作者页](https://fruitrabbit.github.io/WinDEX/)，代码、权重和完整数据许可未核。作者表中流式模型为 171 FPS、腕位误差 42.7mm；它与更准的离线模型不是同一档。相机和机器人命令仍为 30Hz，171 FPS 不能当整链控制率或延迟。长遮挡和跨头戴设备泛化仍有限。
